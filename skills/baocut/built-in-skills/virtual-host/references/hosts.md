# 内置主播：怎么挑

BaoCut 自带一组原创卡通角色，每个都是现成的角色包：会眨眼、呼吸、对口型，带 `smile`、`shy`、`angry`、`sad`、`surprised` 五种表情。用户要虚拟主播、又没有自己的角色（没给照片，也没说要什么长相）时读这一页，从下表推荐。

## 1. 推荐

1. 按片子的内容、观众和语气，从表里挑两三个对得上的；还不知道片子讲什么时先问一句再挑。
2. 用 hosts_list 取缩略图，连同名字和一句「为什么合适」给用户看，让用户选。都不喜欢时，再提出照用户想要的长相生成新角色（`SKILL.md` 第 2 节）。
3. 用户选定后用 hosts_show 取角色包，跳过 `SKILL.md` 第 2 节。
4. 配音的音色照 `narration` 挑，性别、年龄与表里的「配音」对上：成熟男性的角色配少年声、Q 版配低沉的声音都会出戏。
5. 两个主播对话：挑性别或年龄错开、气质有反差的一对（如健司与小夏、莲与小樱），声音好分；各配一个音色，全片不换。

表里的气质与适合的片子是建议，用户点名哪个就用哪个。外貌（发型、眼睛、衣服）在 hosts_list 的 `look`，样子以缩略图为准。
