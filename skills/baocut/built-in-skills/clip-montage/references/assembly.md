# 在 BaoCut 里摆出来

`SKILL.md` 第 7 节的细则。全部用 BaoCut 的工具或 baocut CLI 做；本 skill 不规定流水线的形状，有命令行环境时自己把重复的步骤写成脚本。

目录：1 轨道　2 实拍与照片　3 旁白与原声　4 卡片　5 字幕　6 改一段　7 量一遍

## 1. 轨道

从下到上：

1. **实拍轨**：采访、发布会、录屏、照片、B-roll，首尾相接铺满全片当底；真要留白的几秒放一段黑场或「思考」卡，不留空。
2. **卡片轨**：透明的代码包（推文、引语、日期、下横栏、章节卡、数字），一张一个片段，位置对齐旁白的字时间。
3. **水印轨**（有的话）。
4. 音频：旁白一条；原声跟着实拍片段走（开那个片段的内嵌音频，别的实拍片段静音）；音乐一条。

`addTrack` 建的轨在最上面，用 `moveTrack` 把实拍轨挪到最下面；`videos_inspect` 的 tracks 按叠放次序从下到上列，摆完读一遍核对。

## 2. 实拍与照片

- 旁白先配好、对齐拿到字时间（`narration` 第 4 节），画面再按字时间切：`addItem` 放素材，`trimItem` 裁到那一拍（素材时钟上的入点出点），`moveItem` 对到旁白里那个词被说到的时刻。
- 一拍 3–6 秒；长于十几秒的只在原声或它自己在讲时用。比例对不上的素材选铺满裁切或留边，老画面压暗底，不拉伸。
- 照片与静态截图要动：把照片先做成几秒的视频再当实拍放（本机有 ffmpeg 时用 `zoompan` 做缓慢推拉或平移，3–6 秒走完一个方向），或在透明代码包里画它的推拉。
- 画面上压暗、去色、慢放表达情绪可以，不改变原意；来源角标按 `motion-graphics` 做成小的下横栏或角标。

## 3. 旁白与原声

- 旁白按段配、按段对齐（`narration`）；每段一个音频片段，段与段之间留呼吸。
- 原声片段：实拍轨上放那段视频，裁到字时间定的入点出点，开它的内嵌音频；旁白在这里留白（旁白的下一段从原声结束后 0.3 秒开始）。响度对齐旁白。
- 原声期间卡片轨只放下横栏，不放别的卡。

## 4. 卡片

- 每张卡片是一个自包含的 HTML 画面，透明底，按 `motion-graphics` 写（下横栏、关键词、大数字、标注、章节卡都有骨架）；推文、引语、终端、聊天这几种按它们本来的样子画，不套同一种框。
- 导入即上时间线：`compositions_import` 给 `place.at`（旁白说到那个词的时刻）与 `place.track`（卡片轨）；长度就是卡片的时长，停够读两遍就走。
- 同一时刻只有一张信息卡；卡与卡之间至少隔 0.5 秒。
- 拍不到的东西（流程、规模、时间线、对比）做成一两处代码画面，也是透明叠层，底下实拍继续动；不铺满整屏接管整段。

## 5. 字幕

- 旁白字幕：旁白的转写（或配音时拿到的字时间写成的文稿）用 `captions_create` 建字幕层，照 `subtitle-workflow`。
- 原声字幕：那段视频的转写用 `captions_create` 建，要双语时先按 `translate-subtitles` 写译文再建双语层；字幕只在原声期间显示（裁字幕层上那几条的范围）。
- 卡片上已有的文字不再上字幕。

## 6. 改一段

改稿或换素材时只动那一段：重配那一段旁白、重新对齐、把后面的片段整体挪动（`moveItem` 批量，或按新的字时间重摆），没改的段落沿用原来的录音与画面；卡片改文案时重新导入并给 `replace: { itemId }`，不叠两版。

## 7. 量一遍

量画面占比的脚本在 `production-scripts` 里（用 `skills_read` 读 `production-scripts`，取它的 `scripts/coverage.mjs`）：`node coverage.mjs <videoId>`（连 Runtime，用 `--bc` 指定 baocut CLI 的命令；卡片是透明代码包时加 `--alpha`，它们就不算占帧；或 `--from <videos inspect --limit 1000 --json 存下的文件>` 不连）。它报实拍、代码画面、空白各占屏多少，镜头数与中位长度，最长一段没有实拍，素材重复与带原声的片段，并按分钟画条。这种形式通常实拍八九成、卡片两三成、中位镜头 3–6 秒、没有超过 20 秒没实拍的段落；它只报数，对不对看这期要的是什么。
