# 自检：烘焙前、烘焙后、导出后

`SKILL.md` 第 7 节的细则。历史视频做完不停下等用户确认，这张清单就是用户的那一眼。报告里逐项写：看了什么、看到什么、改了什么；没看的写「没看」。

## 1. 烘焙前（实时层上）

- **从头拖一遍**：审片页从第 0 帧拖到片尾。片头每段看段首、段中、段尾，段与段的交接处前后各看一两秒。
- **看包的帧**：`baocut compositions preview <视频> --path bundles/<id> --at <秒> --at <秒> … --sheet` 一次取一排帧，拼成一张接触表，几秒就好。浏览器面板打开本地 `file://` 的包只是一张静态快照，场景不会动，看不了。
- **第 0 帧**：封面完整：人物的照片、名字、场合与公历日期、照片出处、印章。不从黑场淡入。
- **片头每段**：
  - 没有空着的几秒；
  - 没有叠在一起的字，元素不出画；
  - 生成的图上有「AI 生成示意」；
  - 旁白说到哪里，画面就动到哪里。
- **原声引用**：逐词点亮跟得上声音；响度和旁白接得上（`references/old-recordings.md`）。
- **字幕**：片头与正片都是 KTV，没有逐字高亮，颜色取这期的配色；专名照稿子。
- **正片版面**：
  - 章节序号：加了「背景」一章后从 02 起，看合不合用户的意思；
  - 标题与摘要的换行：查行首标点、落单的字、拆开的人名与书名；
  - 配图出现在讲到它的地方，带图说与出处；
  - 声波跟着录音动。
- **水印与印章**：
  - 角落水印从第 0 帧到最后一帧都在；
  - 画面内水印的次数、位置、时长照 `BRAND.md`；
  - 不压字、不压人脸，不和印章同时出现。
- **章节**：第 0 帧一章「背景」，正片各章的起点对着内容。
- **片尾卡**：许可与声明和 `sources.json` 对得上。
- **实时层画不出的**：代码包上的溶解（那一秒是黑的），以及 `footage.layer` 为 `under` 的段。记下时刻，烘焙后补看。

## 2. 烘焙后

- **每段的 `bake.renderer`**：退回 `browser-pixels` 的段写进报告。
- **时间线没被改乱**：`assemble.mjs --verify` 核对；`videos inspect` 比对烘焙前后：
  - 片段 id 与转场的数目不变；
  - 总长等于各段帧数之和。
- **补看实时层画不出的地方**：片头接正片封面、封面接版面的溶解。用 `baocut export <视频> --kind video --format mp4 --purpose preview --range <起秒>:<止秒>` 导出这几秒看，代码包要先烘焙过。

## 3. 导出后

- **时长与帧数**：`ffprobe` 读出的时长与帧数要等于时间线的长度（帧数 = 秒数 × 帧率）。
- **响度**：导出带了 `--loudness`。用 `ffmpeg -i <成片> -af ebur128=peak=true -f null -` 复测，同一系列各期应该差不多。
- **抽帧**：
  - 第 0 帧；
  - 片头各段；
  - 片头接正片的交接处；
  - 正片封面；
  - 一张配图出现的时候；
  - 一次画面内水印、一次印章；
  - 片尾卡。

  每一帧都要有角落水印。
- **字幕文件**：
  - 条数对；
  - 时间单调递增、没有重叠；
  - 第一条和最后一条对得上成片；
  - 片头旁白与正片合成一份（`srt.mjs`）。
- **章节时间**：从成片取，写进发布文案与说明。
