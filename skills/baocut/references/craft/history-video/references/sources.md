# 找材料、判断许可、记出处

`SKILL.md` 第 3 节的细则。

目录：1 去哪找　2 许可　3 sources.json　4 画面上的出处　5 生成的图

## 1. 去哪找

按可靠程度排，先找一手：

- **录音与影像**：收藏它的档案馆、图书馆、大学特藏的目录页（目录号、日期、权利栏都在那里）；国家档案馆、国会图书馆一类机构的在线目录；广播电台、新闻片公司的档案；Internet Archive 与 Wikimedia Commons 上的镜像只当线索，出处与许可回到收藏机构的目录页核对。
- **讲稿**：当时登载它的报刊、会议记录、政府公报、作者文集；大学的演讲文本项目常附原始出处。网上流传的文本常被删改、合并多次讲话，以录音为准、对照一手文本。
- **照片**：收藏机构的数字馆藏（国会图书馆、各国档案馆、博物馆、大学图书馆）、Wikimedia Commons（每张看文件页的许可与原始出处）、通讯社与报社开放的历史图库（许可各不相同，逐张看）。
- **报刊版面**：数字化的历史报纸库；版面原图有许可时可以直接用，否则只引标题文字、版面由代码画并标为示意。
- **地图数据**：Natural Earth（公有领域）的陆地轮廓；历史边界与战线没有公认、许可干净的数据时只画示意。
- **背景事实**：权威的传记、百科条目只用来找线索，日期、头衔、数字回到一手来源或两个独立来源核对。

搜的时候按人名的几种写法（原文、通行译名、当时的拼法）、场合、年份分别搜；同一次讲话常有不同的标题。

## 2. 许可

逐件判断，记下判断依据（目录页上的哪一栏写了什么）：

- **可以直接用**：收藏机构明确写着公有领域、No Copyright、No known restrictions；CC0；政府作品在其本国公有领域（例如美国联邦政府雇员职务作品）。不同国家的公有领域年限不同，以收藏机构的说明为准，不自己推算。
- **署名后可用**：CC BY、CC BY-SA（成片按 SA 的要求注明许可）。画面上必须写出处（第 4 节），说明里也写。
- **不用，或请用户决定**：许可不明、仅限个人或教育用途、标着版权所有、通讯社的付费图。用户决定用时，记下是用户决定的。
- 录音的许可与讲稿、照片的许可各算各的。
- 只在一个镜像站看到「公有领域」、收藏机构的目录页说法不同时，以收藏机构为准。

## 3. sources.json

出处只记一份，画面、`sources.csv`、说明都从它来：

```json
{
  "items": [
    { "file": "house.jpg", "kind": "photo", "title": "<标题>", "creator": "<作者或机构>", "date": "1943",
      "url": "<目录页或文件页>", "license": "Public domain", "credit": "<画面上的出处一行>", "use": "<用在哪、画面出不出现>" },
    { "id": "speech-record", "kind": "audio", "title": "<录音标题>", "creator": "<收藏机构>", "date": "1943-02-18",
      "url": "<目录页>", "license": "<权利栏原文>", "use": "正片原声；片头引用两段" },
    { "file": "ai-road.jpg", "kind": "image", "title": "<画的是什么>", "ai": true, "license": "<生成它的模型>", "credit": "AI 生成示意", "use": "<哪一拍>" }
  ]
}
```

- `file` 写 `shared/` 下的文件名或原片路径；没有文件的（目录记录、校对用的网页）写 `id`。
- `credit` 用成片语言写，CC BY 系列必须有；公有领域可省，但写上更好。
- `production-scripts` 的 `sources.mjs` 查漏（场景提到的、片段用到的文件有没有条目，有没有 `url` 与 `license`，CC BY 有没有 `credit`），写 `sources.csv`（表头在配置的 `sources.columns`，成片给哪种语言的观众就用哪种语言写）。

## 4. 画面上的出处

- 照片与影像出现时，在画面一角写一行出处（`TIMING.credits[文件名]`），字小、颜色低调，但要清楚到能读；CC BY 的照片每次出现都写。
- 封面上的照片也要写（可以放在角落）。
- 新闻片、照片墙这类一屏多张的，写在最后一张出现时或这一拍的末尾，写全。
- 出处行的字要在打包的字体里有（`build.mjs` 会报缺字）；定稿后改出处行会让那一段重烘，先定好措辞。

## 5. 生成的图

- 只画**没有真人**的场景：地形、道路、天空、物件、抽象的示意。不生成真实人物，不把生成的图当历史照片，不给老照片「修复」「上色」后冒充原片。
- 画面上标明（成片语言的「AI 生成示意」一类字样），`sources.json` 里记 `ai: true` 与模型。
- 提示词照这期的风格说明写，避免年代错误（不该有的车辆、建筑、服饰）；生成后自己看一遍有没有可辨认的字、标志、人脸，有就重生成。
