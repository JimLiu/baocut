# 自检清单

`SKILL.md` 第 7 节的细则，两种用法：

- **缺省**：请用户审片之前，自己先照第 1 节看一遍，改掉看到的问题，再给审片链接。用户说可以以后烘焙、导出，照第 2、3 节核对。
- **用户要自检**（「自检后直接导出」「不用等我确认」）：这张清单代替用户的那一眼，三节都做完再交付。报告里逐项写看了什么、看到什么、改了什么；没看的写「没看」。

清单只查这期对不对得上它自己的简报、风格说明与 `BRAND.md`，不规定这期该长什么样。

## 1. 烘焙前（实时层上）

- **从头拖一遍**：审片页从第 0 帧拖到片尾。片头每段看段首、段中、段尾，段与段的交接处前后各看一两秒。
- **看包的帧**：`baocut compositions preview <视频> --path bundles/<id> --at <秒> --at <秒> … --sheet` 一次取一排帧，拼成一张接触表，几秒就好。浏览器面板打开本地 `file://` 的包只是一张静态快照，场景不会动，看不了。
- **第 0 帧**：一张完成的封面（`SKILL.md` 第 4 节「开头」），不从黑场淡入；封面上该有的元素照 `BRAND.md`。
- **片头每段**：
  - 没有空着的几秒；
  - 没有叠在一起的字，元素不出画；
  - 生成的图上标了「AI 生成示意」；
  - 旁白说到哪里，画面就动到哪里。
- **原声引用**：逐词点亮跟得上声音；响度和旁白接得上（[老录音：修复、拉平、剪开头的空白](old-recordings.md)）。
- **看得清、分得出轻重**：下限、分级与归组照 `video-production` 画面设计细则的第 4.1–4.3 节（读 [`references/craft/video-production.md`](../../video-production.md)，再按它「画面设计」一条读）。
  - 色板过一遍对比度：`node tools/legibility.mjs --bg <底色> 文字=<色> 中间调=<色> 强调=<色> …`（`production-scripts` 的脚本）。没念到、半透明停住的字带上不透明度（`=<色>@0.6`）；照片、地图上的字用它下面那块的颜色当 `--bg`。写字的颜色都要是 `any text`。
  - 列出这期最小的三种字：多少像素、什么角色，够不够下限（时间线上文字的 `fontSize` 乘 2 是像素）。
  - 缩小看：片头每段、正片几处的帧用 `legibility.mjs --frames <图或视频> --at …` 缩到三分之一拼成一张。要读的字都认得出，几级字一眼分得出轻重，没有空着的框和占位图标。
  - 同一种颜色没有同时铺在字幕、章节号、声波与装饰上。
- **字幕**：片头与正片照这期定的样式，两边一个手法；专名照稿子。
- **正片版面**：
  - 章节序号：多了片头那一章后变没变，合不合用户的意思；
  - 标题、摘要、图说的换行：查行首标点、落单的字、拆开的人名与书名；
  - 配图出现在讲到它的地方，带图说与出处；
  - 跟着录音动的画面（声波之类）确实在动。
- **品牌元素**：水印、角标、印章、署名的次数、位置、时长照 `BRAND.md`；不压字、不压人脸。
- **章节**：片头那一章从第 0 帧起，正片各章的起点对着内容。
- **片尾卡**：许可与声明和 `sources.json` 对得上。
- **实时层画不出的**：代码包上的溶解（那一秒是黑的），以及 `footage.layer` 为 `under` 的段。记下时刻，烘焙后补看。

## 2. 烘焙后

- **每段的 `bake.renderer`**：退回 `browser-pixels` 的段写进报告。
- **时间线没被改乱**：`assemble.mjs --verify` 核对；`videos inspect` 比对烘焙前后：
  - 片段 id 与转场的数目不变；
  - 总长等于各段帧数之和。
- **补看实时层画不出的地方**：用 `baocut export <视频> --kind video --format mp4 --purpose preview --range <起秒>:<止秒>` 导出这几秒看，代码包要先烘焙过。

## 3. 导出后

- **时长与帧数**：`ffprobe` 读出的时长与帧数要等于时间线的长度（帧数 = 秒数 × 帧率）。
- **响度**：导出带了 `--loudness`。用 `ffmpeg -i <成片> -af ebur128=peak=true -f null -` 复测，同一系列各期应该差不多。
- **抽帧**：
  - 第 0 帧；
  - 片头各段；
  - 片头接正片的交接处；
  - 正片封面；
  - 一张配图出现的时候；
  - 品牌元素出现的地方（画面内水印、印章之类）；
  - 片尾卡。

  `BRAND.md` 要全片角标时，每一帧都要有。
- **缩小看成片**：`legibility.mjs --frames <成片> --at <片头各段、正片几处>`，同第 1 节。
- **字幕文件**：
  - 条数对；
  - 时间单调递增、没有重叠；
  - 第一条和最后一条对得上成片；
  - 片头旁白与正片合成一份（`srt.mjs`）。
- **章节时间**：从成片取，写进发布文案与说明。
