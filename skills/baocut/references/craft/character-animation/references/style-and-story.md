# 风格与讲法：每期自己定的部分

写风格说明与镜头表时读。下面都是可调的选项，不是规定；用户给了参考或要求时按用户的来。

## 1. 风格的几个旋钮

先写一段两三句的风格说明，之后每张图的提示词逐字复用。不用真实的频道、工作室、作品或人名做参照。

| 旋钮 | 可以怎么选 |
| --- | --- |
| 画法 | 扁平矢量、纸艺剪贴、绘本水彩、复古印刷（网点、错版）、粗线卡通、粉笔画 |
| 线条 | 无描边（靠一层深一点的色块表现体积）或统一粗细的描边。有描边时把手臂的 `edge` 设成描边色 |
| 色板 | 三到五个主色加一个强调色，写色值：每个颜色给谁用（墙、地、衣服、牌子、警示） |
| 角色比例 | 大头（头占身高三分之一，亲切）、写实一点（头占七分之一，严肃）；手臂长度按比例调 `R.sprite(name, { arm })` |
| 演员 | 人、动物（`hand: 'paw'`）、机器人、拟人化的物件（一滴水、一枚硬币） |
| 字 | 粗黑体、手写体、衬线；要覆盖成片语言的全部字符，带 TTF 或 OTF 进包 |
| 转场 | 泼溅、圆形收放、百叶（`R.wipe` 的 `shape`），或全程硬切 |

画幅按平台定：竖版的底图按竖版出，角色站位与牌子都要重新排，不把横版裁一裁。

### 一个定全了数值的例子：扁平信息图

- 画法：纯色块，无描边、无渐变，体积只靠一层深一点的色块。
- 色板：灰蓝、石板青、暖米、藏青、柔紫；肤色鲑鱼粉。
- 角色：大头、点眼。
- 字：800 字重的几何无衬线；白牌子上用 `#2b2d42`。
- 记号：错的想法打红叉（`#d62828`，30 px 圆头，两笔各 0.11 秒）；日期是左上角 330×120 的白卡加 `#f4a261` 日历。
- 大标题：白色 92–96 px 大写，压在 `#e2552f` 加飘动浅色云团，或 `#5b3fa6` 加缓慢转动的 `#6a4cb6` 齿轮上。
- 转场：白色泼溅，进 0.2 秒、出 0.2 秒。

这是一个例子。别的画法照这个粒度定下数值，再写进 `R.style()`。

## 2. 几条默认手艺

好看的动画片多半都遵守这几条；片子需要时可以破例，破例要有理由。

- **画面一直在动**：相机总在慢慢推或摇 2–4%，角色至少在呼吸和眨眼。不动的画面不超过 1 秒。
- **东西靠弹簧、挤压或一团烟出现**（`R.spring`、`R.squash`、`R.puff`），不淡入。
- **字写在世界里**：牌子、黑板、屏幕、楼上的招牌。不飘在画面上，不烧字幕（要字幕用字幕层）。
- **一个想法换一个地方**：每个场景都是一个完整的地方，角色在里面把这句话演出来。
- **不用**：系统 emoji、别人的标志、漂在插画上的界面元素（代码窗口、玻璃卡片、清单）。

## 3. 讲法

先按主题选一种结构，再分给镜头。时长按旁白定。

| 结构 | 适合 | 骨架 |
| --- | --- | --- |
| 翻转认知 | 反直觉的事实、「其实……」 | 钩子推翻观众的默认想法 → 一句惊人的代价 → 揭晓主角 → 它的来历 → 组成或种类 → 「它怎么做到的？」→ 在两三个地方演机制，读数滚到大数字 → 带来的后果与反应 → 反转回扣钩子 → 结尾一句问观众 |
| 跟着一个人 | 真实故事、人物 | 一个具体的时刻 → 他是谁、想要什么 → 第一次失败 → 转折 → 结果 → 今天留下了什么 |
| 跟着一样东西 | 工艺、供应链、「X 是怎么来的」 | 一样东西一路走，每一站一个地方、一个人对它做一件事 |
| 如果…… | 假设题 | 立刻进入那个世界 → 第一天 → 一周后 → 一年后 → 回到现实 |
| 为什么 | 生活里的疑问 | 观众自己的场景 → 常见的错误解释（打叉）→ 真正的原因，演出来 → 所以你可以…… |
| 小剧场 | 品牌、产品、幽默 | 一个人遇到麻烦 → 越弄越糟 → 东西出场 → 反转的笑点 |

短片（1 分钟内）钩子放在头 3 秒，要在关掉声音时也看得懂。结尾让钩子里的角色再出现一次，比结束卡更有力。

## 4. 镜头表

每镜一行：起始的字、地方（底图名）、谁在做什么（动作写具体：走进来、指向牌子、拿起烧瓶、跳起来）、牌子上的字、音效。

- **节奏**：1 分钟的片子每 2–4 秒换一个地方，换想法的句子硬切，大段落之间用转场；更长或更沉静的片子放慢。按内容定，不按秒数凑。
- **每镜的角色都要有动作**：只站着说话的镜头改掉，或者只留很短。
- **反应**：跳（`R.hop`）、转头（`headRot`）、弹出「！」（`R.pop`）是最便宜又最有效的一组。
- **部件表**：镜头表写完列出要出的底图、角色姿势与道具。一张道具网格往往够用很多镜，只画用得上的。
