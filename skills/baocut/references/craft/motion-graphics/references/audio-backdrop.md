# 音频视频的画面设计

给播客、访谈、讲座、口述录音这类说话的音频配一张会被看很久的画面。源是一段说话的影像（历史演讲、讲座、新闻片）时也一样，影像是版面里的一格（第 9 节）。背景、标题、声波、字幕，以及随内容换的配图与章节，是同一张版面，不是几样东西各用各的缺省。这页讲怎么从内容定方案、版面怎么分格、各层怎么落进格子，以及怎么把 HTML 变成背景。时间线上的步骤在说明书工作流页的「音频 → 视频」一节。

本 skill 正文第 1、3 节的时长、停留、42 px 主标题、错峰入场这些数是给叠加图形（下横栏、关键词）的，背景不受它们约束。

## 1. 先定方案，再写 HTML

读用户给的博客正文、简报，没有时读转写的开头几分钟与说话人，写下三行方案再动手：

1. **这一期是什么**：一句话的主题，加语气（冷静、温暖、锋利、轻松、庄重、好奇……）与受众。
2. **画面是什么**：给整张图一个隐喻，比如一张海报、一页书或杂志内页、一张档案卡、一档节目的包装、讲台与灯光、一大片颜色里放一个元素、一张压暗的照片。隐喻决定构图，也决定**谁是视觉重心**：大标题、大声波、一张照片、一扇放影像的窗，或者字幕本身（像书页上的引文那样排成大字主文）。
3. **从内容里取的母题**：只属于这一期的东西，比如一个关键词、一句原话、嘉宾的名字与身份、地点、年代、一个数字，或录音本身的来历（谁、何时、在哪录的、现存何处）。画面里至少有一处来自它，换一期内容时这一处必须跟着换。

方案写进 HTML 源码开头的注释。交付时用一句话告诉用户方向与理由；用户想换时，改方案重出一张。

**同一档节目的系列**：用户说是某档节目的又一期，或视频里已有上一期的背景源码时，先沿用上一期的方案（版式、字、色），只换本期标题与母题。「各有不同」说的是不同内容之间；系列内要认得出是同一档。

## 2. 可调的手段

每一项都在宽范围里按方案取，不固定在某一端：

| 手段 | 范围 |
| --- | --- |
| 明暗 | 浅底、中间调、深底；浅底不比深底「土」，按语气选 |
| 色彩 | 单色系、近乎无彩加一个强调色、两色对比、整片饱和色 |
| 字形 | 黑体、宋体或衬线、楷体、粗重的展示字、等宽；最多两族，计时与数字可另用等宽 |
| 标题尺度 | 从克制的 56 px 小标题，到撑满标题区的 160 px 大字 |
| 对齐 | 居中、左对齐、偏一侧留大片空 |
| 质感 | 平涂、纸张颗粒、柔光渐变、照片或生成图压暗 |
| 装饰 | 不加、一两条细线、超大的期数或引号、一个来自母题的图形 |
| 字幕的角色 | 从底部一两行的配角，到版面正中的大字主文 |
| 声波的角色 | 从版面中央的大声波，到边栏里一条细细的「原声」标识（配计时与标签） |
| 影像的角色（源是影像时） | 从版面的主角（一扇大窗），到大字字幕旁的一张小窗；窗框与调色跟着方案（第 9 节） |
| 随内容换的层 | 不加；章节小标题；说到的人物、刊物、事件、地点的配图与说明（第 6 节） |

**字体**：渲染不联网，只用本机的系统字体；HTML 截成图片后字形就固定了，换机器不变。字体栈按内容的文字写，并以覆盖它的系统字体收尾。例如宋体写 `"Songti SC", "STSong", "Noto Serif CJK SC", "SimSun", serif`，楷体写 `"Kaiti SC", "STKaiti", "KaiTi", serif`，拉丁衬线写 `"Iowan Old Style", Georgia, "Times New Roman", serif`。字体缺失时会静默换成别的字，所以要在预览 PNG 里核对字形确实是想要的那一款。不要用 `Serif`、`Sans` 这类与通用族名同名的族名。

## 3. 美观大方的底线

- 一个视觉重心。留白多于内容；重心比辅助文字明显大（2 倍上下），辅助文字仍守下限：两者冲突时放大重心或删掉辅助文字，不把辅助文字缩到下限以下。
- 看得清、分得出轻重：字号与对比度的下限、字的分级、归组照 `video-production` 画面设计细则的第 4.1–4.3 节（读 [`references/craft/video-production.md`](../../video-production.md)，再按它「画面设计」一条读）。几十分钟的正片里字幕是观众一直在读的主文，其次是章节标题与摘要、图说，最轻的是出处与计时。换成 `fontSize`（540 短边）：字幕 ≥ 24（主文时 28 以上），要读的 ≥ 20，出处与计时 ≥ 14。
- 颜色少而各有分工：底色、文字色、一个强调色，再加一个中间调；渐变也在这几色之内。要分开两类信息（原文与译文、对立的两方）时再加一个色相。强调色不同时铺在字幕、章节号与声波上，中间调用在线、框与未播放的声波上，拿来写字时也要和底色有 4.5:1。
- 文字只放有用的：节目名、本期标题、嘉宾与身份、出处。事实只来自用户的材料、转写与配图的来源页。标题不超过两行，按意群断行。
- 不放一排胶囊标签、假的界面、表情符号、凑数的英文装饰字。
- 第一帧就是封面：缩成缩略图时标题仍读得出。

**这些是千篇一律的信号**，出现时回到第 1 节重想：
- 深蓝紫底加霓虹光晕、网格与居中白字。
- 奶油底加衬线标题与陶土色。

  这两套都是模型的习惯，只在内容真的要求时用。

- 默认青绿声波压在暖色底上。
- 白字黑描边的字幕压在浅色底上。
- 「播客 | 第 X 期」式的占位标题。

## 4. 各层用同一套颜色与字

| 层 | 怎么配 |
| --- | --- |
| 背景与标题 | 方案的底色、文字色与强调色 |
| 内置声波 | `mainColor`（已播放）取强调色或高亮的文字色；`secondaryColor`（未播放）取底色与文字色之间的中间调，与底色有对比但不抢眼。款式默认仍是 `audio_envelope`。`audio_envelope` 框下方有一条进度线与 `mm:ss` 读数；版面另有计时，或声波收得很窄、读数小到看不清时，写 `visualizer.readout: false`，只留细柱与中线。已放好的声波没有改属性的操作：同一笔 `deleteItems`，再按原 `span`、`place` 带上新属性 `insertItems` |
| 字幕 | 深底用浅色字（可以是暖白、冷白），描边关掉或很细，靠柔投影。浅底用文字色深字，关掉描边与投影。照片、花纹等杂底开底板，`backgroundColor` 取底色加透明度。字幕字与背后底色的对比至少 4.5:1。字幕做主文时，字跟版面走：`fontFamily` 写系统字体名（如 `Songti SC`），`fontWeight` 400 上下，`lineHeight` 1.3–1.6，`punct: false` 留住标点 |
| 字幕的念到效果 | 默认不逐字高亮：引擎的缺省样式把当前词染成青绿色，建层时 `baocut captions create` 的 `style` 写 `"wordAnimation": {"catalogId": "none"}`，已有的字幕用 `setCaptionStyle` 写同一个键。要 KTV（念到哪里，哪里的颜色变深）时改写 `"textMotion": {"karaoke": {"color": 念过的颜色}}`，当前词会一起换成 none，原有的入场、出场保留；没念到的颜色是 `fontColor`。两个颜色都从这一期的色板取：浅底上中灰到墨色，深底上暗一点的中间调到更亮或更暖的强调色。没念到的颜色也要和底色有 4.5:1（观众会往前读），念过的靠更深或换色相来分，不把没念到的淡到看不清。只有带词时间的字幕会扫色；双语的译文行借原文的词时间一起扫 |
| 配图说明、章节、计时 | 文字实例，与背景同一套字与色：标题用正文那一族，摘要与图说小一级（`fontSize` ≥ 20），出处与计时再小一级（≥ 14）；颜色都和底色有 4.5:1，中间调不够就加深 |

字幕换字体后，导出一小段预览确认字形生效：系统里没有这一族时会换成别的字。

## 5. 版面：先分格，再落位

背景、字幕、声波与配图落在同一张格子上，画面才浑然一体。先在画布像素上定几块区域，写进 HTML 开头的注释。HTML 只画不变的框架：底色、细线、刊头、标签、大引号、页脚。会变的东西放成时间线上的实例：字幕、声波、配图、章节标题、计时。它们的坐标从同一张格子换算，这样能对上线，用户也还能逐个改。

常见的区（按方案取舍，不照抄）：

| 区 | 放什么 |
| --- | --- |
| 刊头 | 节目名或人名、语言、期数 |
| 标题区 | 本期标题，或按章节换的小标题 |
| 主区 | 视觉重心：大标题、大声波、照片，或大字字幕 |
| 边栏或底栏 | 配图与说明、小声波、计时、「原声」之类的标签 |
| 页脚 | 录音出处、馆藏、配图来源 |

像素换成实例坐标（画布宽 W、高 H，结果是百分比）：

- **字幕**：折行区左右边 L、R，顶边 T。写 `x = (L+R)/2/W×100`，`width = (R−L)/W×100`，`y = T/H×100`，`verticalAlign: "top"`。要左对齐贴住 L，写 `textAlign: "left"` 加 `alignWithinWrap: true`；不加时字幕块按字长居中，短句会漂在中间。`fontSize` 按 540 短边算：1080 高的画面上 88 px 的字写 44。字幕块往下长，主区要留够两行。
- **文字实例**（`insertItems` 的 `text`）：字段是 `text`（或计时的 `counter`）、`style`、`verticalAlign`（`top` | `center` | `bottom`，`place.y` 钉住块的哪一处）与 `place`。`style` 用字幕样式的同名键：`fontFamily`、`fontSize`（540 短边下的像素）、`fontWeight`、`fontColor`、`textAlign`、`lineHeight`、`letterSpacing`、`textOutline`、`dropShadow`。`place.x` 是框中心，`place.w` 是框宽：左边 L、宽 w 的框写 `x = (L + w/2)/W×100`，`w = w/W×100`；`textAlign: "left"` 时字贴框的左边。文字按 `place.w` 折行，中文图注要在意群处断时在 `text` 里写 `\n`，免得书名号里断开或剩一个字一行。同一条轨道上的实例不能重叠，同时出现的几行字各放一条轨道。
- **声波**：`audio_envelope` 的框高约 `W × w% × 340 / 1632`，`scaleY = 框高 / (H × 0.2)`。`place.y` 是框中心；柱子在框高的 13%–63%，柱子中心比框中心高出框高的 12%，读数在最下面。`readout: false` 时下面空着，要让柱子落在格子中线 Y 上，写 `place.y = (Y + 0.12 × 框高)/H×100`。
- **画中画配图**（`mode: "pip"`）：框宽由 `place.w` 定，框高由图的宽高比定。要放进固定的 w×h 格子，按格子比例 `r = w/h` 和图的比例 `a = 图宽/图高` 用 `crop` 裁：图比格子宽（`a > r`）时左右各裁 `(1 − r/a)/2`；比格子高时上下共裁 `1 − a/r`，人像多裁下面、留住头部。`place.x`、`place.y` 是格子中心。

换算完把每层的左右边与 HTML 注释里的格子线逐一对一遍：手算时常把一层的 L 写错，背景上的线对不上，要到看帧时才发现。

声波居中、字幕在下的默认摆位，各层占的位置（像素按画布）：

| 画幅 | 标题区 | 内置声波 | 字幕（两行） |
| --- | --- | --- | --- |
| 1920×1080 | y 约 90–390 | `y:54, w:85`：框 y 413–753、x 144–1776，柱子在 y 458–630，下面是进度线与时间 | 中线 y 929，约 y 857–1001 |
| 1080×1920 | y 约 180–800 | 中上，例如 `y:50, w:85`：框 y 864–1056 | `y:78` 底边对齐：约 y 1360–1500；y 1690 以下是平台控件 |

**一个做法示例**（不是模板）：素材是哈佛馆藏、六十年代末的张爱玲英文录音，观众说中文。内容是档案、年代久远，方案定为「档案馆里的一页书」：米色纸底、墨色宋体、一个暗红强调色。
- 刊头是英文人名；标题区按两章放编号、章节标题与一句提要。
- 主区是中文译文字幕：宋体 44 号、左对齐贴边、留标点，左上方有一个暗红大引号。
- 底栏左边是这一段说到的刊物或人物的小照片，旁边写名称、年代与「Wikimedia Commons · Public domain」；右边是收窄的暗红声波（`readout: false`）、「原声」标签与 `mm:ss` 计时。
- 页脚写馆藏出处。

换一段录音，隐喻、色、字与格子都要跟着重想。

- 声波与字幕背后要「静」：不放文字、细碎纹理与高对比的边；渐变与大色块可以穿过。
- 设计时在 HTML 里临时加几层半透明色块，标出字幕、声波与配图各占的格子，预览一帧看构图；定稿前删掉这几层再截图。

## 6. 随内容换的层：配图、章节、计时

几十分钟只有一张静图会闷。让画面跟着说的内容换，比让背景动更有用。

- **配图**：转写里说到具体的人、刊物、事件、地点时，用 `baocut assets search` 加 `kind: image` 找。它只查 Wikimedia Commons 与 Internet Archive，按文件标题与说明匹配：`query` 用英文写人名、作品名、地名这类名词，可加年代（如 `Leo Tolstoy 1908`），不写一句描述，描述性的词常常一条也搜不到。`preview: true` 先看接触表再挑。
  - 优先用 public-domain、cc0；cc-by 要署名；cc-by-sa 先告诉用户；许可没写清的不用。
  - 用 `baocut assets download` 导进视频。档案照片常带卡纸衬边、扫描黑边或手写编号：放进格子后用 `baocut videos frames` 看一帧，`crop` 只留照片本体。
  - 每张图从它被说到的时候起，铺到下一张图出现为止，放在同一条画面轨上首尾相接；相邻两张之间可以用 `setTransition` 加 0.3–0.6 秒的 `dissolve`。图旁的名称与出处文字硬切，不加溶解：两行字叠在一起会糊成一团。
  - 旁边用文字实例写名称、年代或一句说明，再小一级写「来源 · 许可」（不小于 28 px，`fontSize` 14）。
  - 配图的框线、底板跟着图片出现，不画进静态背景：没有图的时段背景上就不会剩一个空框。图少的录音，版面不给配图留固定的一大格，让字幕或章节摘要占那块地方。
  - 没有合适、许可干净的图就不放；不用生成图冒充史料照片。
- **章节小标题**（可选）：章节不会自动出现：转写润色后照字幕流程的默认，按 `video-chapters` 自己分、写进视频。这里说的是画面上放不放章节小标题。有两章以上时放；只有一章、没分出章，或录音短到只讲一件事时不放，标题区留给本期标题。
  - 用章节文字：在标题区放一个文字实例，写 `chapter: {"field": "title"}`（不写 `text`），从第 0 帧铺到片尾。引擎每一帧画此刻所在章节的标题，第一章开始之前不画；章节改名、增删或被剪辑挪动后自动跟着变，不用再改实例，也不按章拆成多个实例。
  - 要编号、提要时各加一个同样铺满全片的实例：`{"field": "number", "numberFormat": "01"}`（`"1/N"` 画成「3/7」），`{"field": "summary"}`（取章节的 `summary`，没写摘要的那一章不画）。几个实例用同一套字与颜色；章节标题当副标题用，不抢刊头。
  - 语言跟字幕主文走：录音要译成观众的语言时（字幕主文是译文），章节的标题与摘要用观众的语言写，人名、术语跟译文一致。作者的章节先带 `dryRun` 调 `baocut chapters adopt` 看回执的 `rows`，再用 `outline`（`[{ at: sourceAt, title }]`，标题换成观众的语言）正式采用，时间仍照作者的。画面上的章节文字画的就是视频的章节：要换字就改章节，不另写 `text` 实例，也不在实例里手写译名。章节只存一种语言，原文与译文两行的章节标题做不到，只放观众语言的那一行。
  - 也可以按章节换背景的变体：同一套版式，换强调色或母题；图片实例在章节边界首尾相接。
- **计时**：文字实例写 `counter: {"mode": "countup", "format": "mm:ss"}`（超过一小时用 `hh:mm:ss`），从第 0 帧铺到片尾，放在声波旁边或页脚。有了它就关掉声波的 `readout`，画面上不出现两个时间。

## 7. 静态背景：HTML 截成一张图

长录音默认走这条：

1. 从骨架起一个源目录（放在工作目录里，例如 `backdrops/<视频名>/index.html`）。
   - `#root` 的尺寸与画幅一致；在布局槽里另写一条 `#root{background:…}`，给整张底色。
   - 不写入场动画，元素一开始就在位。
   - 只画格子里不变的部分；字幕、声波、配图、章节标题与计时不画进去。
   - 保留骨架其余部分，`baocut compositions preview` 才能取帧。
2. `baocut compositions preview` 在出场淡出之前取一帧（4 s 的骨架取 `"1"`），得到 PNG。看字形、构图与留位。
3. 一笔 `baocut edits apply`：`importAsset` 导入这张 PNG，`insertItems` 在最下面的画面轨放一个图片实例。`span` 从第 0 帧到 `sequence.durationFrames`，铺满（`mode: "fullscreen"`、`fit: "cover"`）。
4. 源目录留着，告诉用户在哪；改版时改 HTML、重截、换图。换图用一笔 `baocut edits apply`：`importAsset` 导入新图（带 `ref`），`replaceItemAsset` 用 `assetImportRef` 把背景实例换过去，不给 `timeMap`。实例的 ID、`span`、`mode`、`fit` 与挂在上面的转场都不动。

## 8. 会动的背景

只在录音短（几分钟内）或用户要求时做：
- 整段一个合成，时长等于音频。
- 动得慢而连续：用 `Math.sin` 的周期运动，周期 8 秒以上；根元素加 `data-motion-continuous="true"`。
- 骨架的统一出场正好用作片尾收束。

不要做一段短循环再重复摆放：每一段到结尾都会整体淡出，画面一闪一闪。先用 `baocut compositions import` 的 `live: true` 给实时预览，定稿后再烘焙。长录音烘焙要很久，宁可用第 7 节的静图，加第 6 节随内容换的层。

## 9. 有影像时：画面放进一格

源是一段说话的影像（历史演讲、讲座、新闻片、档案采访）时，影像也是版面上的一层：格子里的一扇窗，背景、字幕、章节与配图围着它排。

**什么时候开窗**：
- 影像低清（480p 及以下）、4:3 或更窄、边上有黑边或胶片的脏边、黑白与彩色混着，或者要放的是字幕、译文与背景信息，这时开窗。铺满 16:9 会把旧影像放大得发糊，左右两条黑边又像没做完。
- 高清 16:9 的现代讲座多半仍铺满，只加下横栏与字幕；用户要这种版式时也开窗。

**先量素材**：
- 源的像素尺寸看 `baocut videos inspect` 素材列表的 `size`。
- 用 `baocut videos frames` 取开头、中间几帧，找烧进画面的黑边、时间码、台标、胶片边缘的划痕与暗角，用 `crop` 裁掉。每次加 1%–3%，改完再看一帧。4:3 的内容装在 16:9 文件里时，左右各裁 `(1 − (4/3)/(16/9))/2 = 0.125`。
- 影像中途切到观众、字卡是正常的，不用剪。

**窗多大**：
- 窗宽不超过源宽（裁后）的 2.5 倍左右：334 px 宽的源放到 770 px 还看得过去，再大就糊。竖版里低清的源不要撑满 1080 的宽，收窄、四周留边。
- 窗高跟着裁后的宽高比走，不能单独指定。画布宽 W、高 H，源宽 sw、高 sh，裁切四边比例 l、t、r、b：
  - 窗宽 `ww = place.w/100 × W`
  - 窗高 `wh = ww × sh × (1 − t − b) / (sw × (1 − l − r))`
- 所以先按影像的比例定这一格，再排别的层；不要为了塞进随手定的格子把人裁掉。
- `place.x`、`place.y` 是窗的中心：左边 L、顶边 T 的窗写 `x = (L + ww/2)/W×100`，`y = (T + wh/2)/H×100`。

**怎么放**（一笔 `baocut edits apply`；影像被切成几段时每段都写）：
- `setStyle`：`mode: "pip"`；`crop` 裁黑边与脏边；`radius` 按方案，档案感多用 0 或很小。
- `setTransform`：`x`、`y`、`w` 按上面换算。
- `setEffects` 整份替换 `fx`，要的都写上：
  - 窗框用 `stroke`（方案的线色，1–3 px）或 `shadow` 让窗浮起来。也可以在 HTML 背景里按窗的像素画衬底或画框，线要与窗边对齐。
  - 调色只为与版面一致：黑白片偏色时 `grayscale: 1`；`contrast`、`brightness`、`temperature` 小幅调。彩色片不必改成黑白。
- 背景图要在影像下面：`baocut transcribe` 把影像放在最下面的画面轨上，新加的轨道排在最上面。背景图放上之后，再提交一笔 `arrangeItem`（`direction: "back"`，`itemId` 是上一笔回执 `createdIds` 里 `item_` 开头的那个）把它挪到最下面。

**别的层**：
- 字幕不压在影像上，放在窗旁或窗下自己的区里。
- 声波可以不放，影像本身在动。要留「原声」标识时收窄、写 `readout: false`，放在窗下或页脚。
- 配图、章节小标题与计时照第 6 节，放在别的格里，不盖住影像。
- 影像的出处写在窗下或页脚：用 `baocut assets download` 导进视频的，`baocut videos inspect` 素材的 `credit` 里有许可与署名；用户给的文件按用户的材料写，没有就问，不编。

**一个做法示例**（不是模板）：1941 年罗斯福在国会的「国耻日」演讲，新闻片 480×360、黑白，观众说中文。方案是「战时报纸的一版」：
- 报纸灰白底、黑色粗宋体、一个暗红强调色。
- 左侧 3/5 是窗：宽 1060 px（约 2.2 倍），`grayscale: 1`，2 px 黑框；窗下一行小字写出处。
- 右栏顶上是报头式的日期，下面是中文译文字幕，左对齐；按章换小标题。

换一段影像，隐喻、色、字与窗的位置都要跟着重想。
