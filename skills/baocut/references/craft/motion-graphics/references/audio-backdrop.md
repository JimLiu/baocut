# 音频视频的画面设计

给播客、访谈、讲座这类说话的音频配一张会被看很久的画面：背景、标题、内置声波与字幕是同一张设计，不是四样东西各用各的缺省。这页讲怎么从内容定方案、各层怎么配、版面留给谁，以及怎么把 HTML 变成背景。时间线上的步骤见 `baocut-workflows` 的「音频 → 视频」。

本 skill 正文第 1、3 节的时长、停留、42 px 主标题、错峰入场这些数是给叠加图形（下横栏、关键词）的，背景不受它们约束。

## 1. 先定方案，再写 HTML

读用户给的博客正文、简报，没有时读转写的开头几分钟与说话人，写下三行方案再动手：

1. **这一期是什么**：一句话的主题，加语气（冷静、温暖、锋利、轻松、庄重、好奇……）与受众。
2. **画面是什么**：给整张图一个隐喻，比如一张海报、一页书或杂志内页、一档节目的包装、讲台与灯光、一大片颜色里放一个元素、纸本印刷、一张压暗的照片。隐喻决定构图，不先想装饰。
3. **从内容里取的母题**：只属于这一期的东西：一个关键词、一句原话、嘉宾的名字与身份、地点、年代、一个数字。画面里至少有一处来自它，换一期内容时这一处必须跟着换。

方案写进 HTML 源码开头的注释；交付时用一句话告诉用户方向与理由，用户想换时改方案重出一张。

**同一档节目的系列**：用户说是某档节目的又一期，或视频里已有上一期的背景源码时，先沿用上一期的方案（版式、字、色），只换本期标题与母题。各有不同说的是不同内容之间，系列内要认得出是同一档。

## 2. 可调的手段

每一项都在宽范围里按方案取，不固定在某一端：

| 手段 | 范围 |
| --- | --- |
| 明暗 | 浅底、中间调、深底；浅底不比深底「土」，按语气选 |
| 色彩 | 单色系、近乎无彩加一个强调色、两色对比、整片饱和色 |
| 字形 | 黑体、宋体或衬线、楷体、粗重的展示字、等宽；最多两族 |
| 标题尺度 | 克制的 56 px 小标题，到撑满标题区的 160 px 大字 |
| 对齐 | 居中、左对齐、偏一侧留大片空 |
| 质感 | 平涂、纸张颗粒、柔光渐变、照片或生成图压暗 |
| 装饰 | 不加、一两条细线、超大的期数或引号、一个来自母题的图形 |

**字体**：渲染不联网，只用本机的系统字体；HTML 截成图片后字形就固定了，换机器不变。字体栈按内容的文字写，并以覆盖它的系统字体收尾，例如宋体 `"Songti SC", "STSong", "Noto Serif CJK SC", "SimSun", serif`，楷体 `"Kaiti SC", "STKaiti", "KaiTi", serif`，拉丁衬线 `"Iowan Old Style", Georgia, "Times New Roman", serif`。字体缺失时会静默换成别的字：在预览 PNG 里核对字形确实是想要的那一款；不要用 `Serif`、`Sans` 这类与通用族名同名的族名。

## 3. 美观大方的底线

- 一个视觉重心。留白多于内容；标题与辅助文字的字号至少差 2.5 倍。
- 颜色少：底色、文字色、一个强调色，再加一个中间调；渐变也在这几色之内。
- 文字只放有用的：节目名、本期标题、嘉宾与身份，事实只来自用户的材料与转写。标题不超过两行，按意群断行。
- 不放一排胶囊标签、假的界面、表情符号、凑数的英文装饰字。
- 第一帧就是封面：缩成缩略图时标题仍读得出。

**这些是千篇一律的信号**，出现时回到第 1 节重想：深蓝紫底加霓虹光晕、网格与居中白字；奶油底加衬线标题与陶土色（这两套都是模型的习惯，只在内容真的要求时用）；默认青绿声波压在暖色底上；白字黑描边的字幕压在浅色底上；「播客 | 第 X 期」式的占位标题。

## 4. 各层用同一套颜色

| 层 | 怎么配 |
| --- | --- |
| 背景与标题 | 方案的底色、文字色与强调色 |
| 内置声波 | `mainColor`（已播放）取强调色或高亮的文字色；`secondaryColor`（未播放）取底色与文字色之间的中间调，与底色有对比但不抢眼。款式默认仍是 `audio_envelope`，只改色与位置。已放好的声波没有改色的操作：同一笔 `deleteItems` 再按原 `span`、`place` 带上颜色 `insertItems` |
| 字幕 | 深底：浅色字（可以是暖白、冷白），描边关掉或很细，靠柔投影；浅底：文字色深字，关掉描边与投影；照片、花纹等杂底：开底板，`backgroundColor` 取底色加透明度。字幕字与背后底色的对比至少 4.5:1 |
| 字幕的当前词高亮 | 缺省是青绿色，`setCaptionStyle` 改不到：用 `baocut edits apply` 的 `patchDocument` 改字幕样式文档（字幕实例的 `styleDocumentId`；还没有时先 `setCaptionStyle` 一次，回执的 `createdIds` 里就是它），路径 `["style","wordAnimation","active","color"]`，取强调色；强调色在这片底上不够深时取它深一档，或直接取字幕字色 |
| 章节小标题（可选） | 文字实例，与标题同一套字与色，放在标题区里不抢主标题 |

字幕换字体（`fontFamily`）时要导出预览确认生效；没把握就留 `system`，靠颜色、描边与底板配。

## 5. 版面：给声波和字幕留位

默认摆位下，各层在画面里占的位置（像素按画布）：

| 画幅 | 标题区 | 内置声波 | 字幕（两行） |
| --- | --- | --- | --- |
| 1920×1080 | y 约 90–390 | `y:54, w:85`：框 y 413–753、x 144–1776，柱子在 y 458–630，下面是进度线与时间 | 中线 y 929，约 y 857–1001 |
| 1080×1920 | y 约 180–800 | 中上，例如 `y:50, w:85`：框 y 864–1056 | `y:78` 底边对齐：约 y 1360–1500；y 1690 以下是平台控件 |

- 声波与字幕背后要「静」：不放文字、细碎纹理与高对比的边，渐变与大色块可以穿过。
- 声波的位置与大小是版式的一部分，可以随方案改（例如左对齐版式把声波收窄靠左）。改了按 `scaleY = (画布宽 × w% × 340) / (1632 × 画布高 × 0.2)` 保持比例，框高约 `画布宽 × w% × 340 / 1632`，重新量过上表的位置，仍不压字幕。
- 设计时在 HTML 里临时加一层半透明色块标出声波带与字幕带，预览一帧看构图，定稿前删掉这一层再截图。

## 6. 静态背景：HTML 截成一张图

长录音默认走这条：

1. 从骨架起一个源目录（工作目录里，例如 `backdrops/<视频名>/index.html`）：`#root` 的尺寸与画幅一致；在布局槽里另写一条 `#root{background:…}` 给整张底色；不写入场动画，元素一开始就在位。保留骨架其余部分，`baocut compositions preview` 才能取帧。
2. `baocut compositions preview` 在出场淡出之前取一帧（4 s 的骨架取 `"1"`），得到 PNG；看字形、构图、留位。
3. 一笔 `baocut edits apply`：`importAsset` 导入这张 PNG，`insertItems` 放一个图片实例在最下面的画面轨，`span` 从第 0 帧到 `sequence.durationFrames`，铺满（`mode: "fullscreen"`、`fit: "cover"`）。
4. 源目录留着，告诉用户在哪；改版时改 HTML、重截、换图。

**随时间变化**：几十分钟的录音只有一张静图会闷。有章节时（怎么分读 [`references/craft/video-chapters.md`](../../video-chapters.md)），可在标题区按章节放小标题文字实例，每段铺满它那一章；或按章节换背景的变体（同一套版式，换强调色或母题），图片实例在章节边界首尾相接。

## 7. 会动的背景

只在录音短（几分钟内）或用户要求时做：整段一个合成，时长等于音频，动得慢而连续（`Math.sin` 的周期运动，周期 8 秒以上），根元素加 `data-motion-continuous="true"`；骨架的统一出场正好是片尾收束。不要做一段短循环再重复摆放：每一段到结尾都会整体淡出，画面一闪一闪。先用 `baocut compositions import` 的 `live: true` 给实时预览，定稿后再烘焙；长录音烘焙要很久，宁可用第 6 节的静图加章节变化。
