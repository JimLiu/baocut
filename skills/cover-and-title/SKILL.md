# 封面与标题

封面和标题是一起被看到的：标题说清这是什么，封面给画面和钩子。两者补充，不互相照抄。写给发布视频的人：吸引人，并且每句都由视频兑现。

## 1. 取材料

1. 用 videos_inspect 看视频：名字、画幅（宽高）、章节、文档。没有转写（kind 为 speech 的文档）时先转写，告诉用户转写在进行。
2. 读文稿：export（kind `transcript`、format `md`、timestamps `true`），jobs_inspect 等到 completed，读 outputs 里的文件。
3. 用户这次的要求：几组、封面字数上限、风格、语言、发布平台、已经挑定的标题，都在这段对话里找。没说语言时用文稿的语言。

## 2. 出标题与封面文案

1. 先用一句话说清这部视频给观众什么：解决什么问题、给出什么结论或看到什么。
2. 给出几组候选（用户没说就 5 组），角度各不相同：直述、提问、数字、反差、引语之类。每组是一条标题加一行封面大字。
3. 封面大字要短（用户没说时按这种文字的习惯取几个词以内，中日文约 8 个字以内），一眼能读完，不重复标题原话。
4. 标题与封面里的数字、结论、人名都必须能在文稿里找到出处；不用夸张的断言，不许诺视频没给的东西。
5. 每组附一句理由，标出推荐的一组，请用户挑一组，或说要再来一批、照哪组再来几组。

## 3. 生成封面

用户挑定一组之后再做，不要先把几组都生成出来。

1. **画面从哪来**：先用 videos_frames 在章节起点与情绪、动作明显的地方取几帧看，找人物或主体清楚、表情或动作有张力的一帧。
2. **生成**：用 image 给 `prompt`、按视频画幅给 `size`（宽高比如 `16:9`、`9:16`、`1:1`，用户点名的比例优先；模型不支持这个比例时取它支持的最接近的一种，并告诉用户），带上 `video`，结果导入为这个视频的候选素材，不放上时间线。image 不接受参考图：在提示词里写清主体、构图与风格（人物或主体在一侧，大字留在另一侧的干净区域），把挑中那一帧的画面描述进去；用户要真人照片的封面时，告诉用户可以直接用那一帧，大字由用户在平台或编辑器里加。
3. **大字**：生成的图里文字常常写错。提示词里要求留出干净的大字区域；用户要图里带字时，生成后读一遍图，字写错了就重来或告诉用户。
4. 用户没说张数时生成 2 张，`count` 给 2。

## 4. 交付

- 回复里给出用户挑定的标题与封面大字，以及其余候选，方便以后再换。
- 封面图：image 返回的每张 `artifactId` 与导入的素材；说明用的是哪一帧或怎样的描述、为什么选它。
- 哪些信息没有核实；说了平台的，提醒用户对照平台现行的封面尺寸与文字规则核对。
