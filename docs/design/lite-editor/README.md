# docs/design/lite-editor/ — 轻量编辑器

同一部视频的另一种看法：画面居中、底下是按段分格的进度条、右边是当前段的脚本与逐句台词，画面上可以直接画标记发给会话。给的是「看一遍、指出哪里要改」的人，不是调节奏的人；时间线视图仍在，顶栏一键切换，两边共用一份状态。建立在[产品设计 §5](../../product/product-design.md#5-编辑器) 与[章节化代码动画片](../motion-video/README.md)之上，只写增加的部分。
