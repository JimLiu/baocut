# 12. 分页与预算参数表（8000 词起始压测值）

> 出自 [BaoCut 文件契约字幕 AI 管线设计（File-Contract Pipeline, v0.3）](../bcut-file-contract-subtitle-ai-design.md)

**计量口径统一为词数**：Agent 页预算以 `atomize::word_count` 计量——CJK
逐字计一词、Latin 按词计一词、依附标点不计数。分页只由源文词数决定，
句数、序列化字符数和执行并发都不参与页形；worker 槽数只控制消费并发。
polish 的核心区预算独立保留为 2200 词，以现有稳定基线作为对照。

| 阶段 | 页预算（词） | 上下文 | 并行 | 内容重试上限 |
|---|---|---|---|---|
| analysis | 8000 | 无 | map 并行，reduce 串行（短稿 1 次调用；"3"是重试上限，不是阶段数） | 3 |
| segment | 8000 | 无 | 批量 | 3 |
| polish+segment | 核心 2200 | 两侧各 min(200 词, 3 句)，≥1 完整句 | 批量（需加入 parallel_kind） | 3 + span 2 |
| translate | 8000 / 整段对齐 | 注释语境 | 批量 | 句级 3（三波） |
| align | 8000 | 前后各 1 句只读 | 批量 | 2 轮 |

执行并发沿用：agent workers（`BCUT_LLM_MAX_WORKERS`）/ provider lanes
（`BCUT_PROVIDER_MAX_LANES`）；并发数不再反馈分页粒度。

**现行实现口径**：

| 阶段 | 落地值 | 口径 | 与设计的差 |
|---|---|---|---|
| analysis | `budgets::ANALYSIS = 8000` | 源文词 | 一致 |
| segment | `budgets::SEGMENT = 8000` | 源文词 | 一致 |
| translate（文件契约） | `TRANSLATE_FILE_WORDS = 8000` | 源文词 | 一致 |
| polish 核心区 | `PolishBudget::core_words = 2200`，上下文 200 词 / 3 句、溢出比 0.15 | 词 | 一致；但雪球守卫的溢出检查仍按 `chars` 算 |
| align 装箱 | `ALIGN_FILE_WORDS = 8000` | 源文词 | 全量、定点修复与全局修复共用；无句数/字符附加上限 |
