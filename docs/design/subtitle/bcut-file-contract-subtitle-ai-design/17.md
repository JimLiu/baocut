# 17. 开放问题与已知缺口

> 出自 [BaoCut 文件契约字幕 AI 管线设计（File-Contract Pipeline, v0.3）](../bcut-file-contract-subtitle-ai-design.md)

## 17.1 待压测标定（原 v0.2 条目，仍开放）

- 翻译/对齐 8000 词预算与 polish 页级匹配门槛 0.7 在大页下的重标定（压测）。

- `report.json` 与现行 `ai/polish.json` 消费方的字段兼容清单终稿。

- v2 是否需要参考 B 的 `TextPatchSet` 重叠合并（仅当只读上下文方案的缝质量被压测证伪）。
