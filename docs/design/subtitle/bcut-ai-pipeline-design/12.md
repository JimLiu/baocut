# 12. 实施状态

> 出自 [bcut 转录后处理 AI 管线技术方案（润色 / 分段 / 分章节 / 翻译 / 字幕对齐）](../bcut-ai-pipeline-design.md)

| 阶段 | 内容 | 依赖 | 验收 |
| --- | --- | --- | --- |
| **P0（完成）** | MOSS 词时间补齐、rows → v0.3 transcript、词序校验 | 无 | 两类 ASR 路径统一词原子格式 |
| **P1（完成）** | fingerprint/paging/rebind/progress、`LlmJson`、provider + agent 执行器 | P0 | 离线引擎与 task 回环回归通过 |
| **P2（完成）** | brief + polish + review | P1 | 分页、续跑、id/时间不变量回归通过 |
| **P3（完成）** | segment + chapters | P2 | 降级阶梯、清洗与幂等回归通过 |
| **P4（完成）** | 句级 translate + display split/align + stale-only | P3 | 双向 id、visible fingerprint 与定向重跑回归通过 |
| **P5（完成）** | 字幕/文稿/MP4/工程导出消费与 check | P4 | 原文/译文/双语全链路回归通过 |
| **P6（完成）** | 最终时间线跨源路由、可见词子序列对齐、分源 review/checkpoint 与 UI 写回 | P4 | 多源/剪切/复用/跨 cut 合并/附加源编辑回归通过 |

风险与对策：

- **中文分词的 atomize 质量**决定 LCS 映射成功率——P1 先移植 voice-ink 的
  `SubText.atomize`（CJK 逐字 + Latin 词）并以其测试集对拍，不自研分词;
- **Rust 侧无现成 LLM SDK 依赖**——刻意保持：请求就是一个 POST JSON，
  `ureq` 足够；流式（进度/亚秒取消）推迟到需要时再评估 `reqwest`;
- **agent 模式的 lint 即引擎校验**——必须做到同一份校验代码两个执行器复用，
  否则 provider 与 agent 的产物质量会漂移。
