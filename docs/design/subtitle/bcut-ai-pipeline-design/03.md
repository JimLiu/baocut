# 3. 数据与状态

> 出自 [bcut 转录后处理 AI 管线技术方案（润色 / 分段 / 分章节 / 翻译 / 字幕对齐）](../bcut-ai-pipeline-design.md)

## 3.1 词原子是唯一真相（继承格式规范 §18）

全管线的读写对象是 §18 的 transcript 文档：`words[]` 是唯一持久化的文本与时间来源；
Cue / Para 按 §18.5 规范算法派生；用户与 AI 的结构性干预都落在以词 id 为键的稀疏覆盖表
（`breaks` / `paraBreaks` / `hidden`）。**本方案不新增任何与词并行的源文本存储**——润色改词、
分段写覆盖表；完整自然译句挂在派生 Sentence 的 id 上，对齐片只是展示覆盖层。

现有 `bcut-speech-core` 的 `transcript.json` v0.1（rows 契约）降级为 **ASR 原始产物**，
落 `ai/asr-rows.json` 供审计与重建；面向编辑与管线的规范文档是 §18 词原子 transcript，
由阶段〇的确定性 build 步骤生成（§4.3）。
`bcut project seed-transcript <project>` 的 stdin 同时接受这份 0.1 rows 契约；写入空项目时
复用与转录相同的 `build_doc`、CJK AutoCorrect 和校验路径，同时保存审计副本。这样回归实验
可从同一次模型推理重建原始词流，不必重跑 ASR，也不能用已润色正文冒充原始输入。rows
里的语言与媒体 path/hash/duration 同步回项目清单，替换 `project create` 尚未转录时的占位值。

## 3.2 指纹：两种，用途严格区分

移植 voice-ink 的 FNV-1a 方案（`offset 0xcbf29ce484222325`，`prime 0x100000001b3`，
值间分隔符 `hash ^= 0x1f`）：

```rust
// bcut-flow-core/src/fingerprint.rs
/// 内容指纹：哈希每个词的 text。文本编辑即失效。
/// 形如 "1234:g1.0:g87.4:k3f9…"（count:firstId:lastId:base36hash）
pub fn fingerprint(words: &[Word]) -> String;

/// 结构指纹：只哈希每个词的 id。文本编辑存活（rebind 保 id），重转录失效（id 全换发）。
pub fn id_fingerprint(words: &[Word]) -> String;

pub fn fingerprint_strings<I: IntoIterator<Item = String>>(items: I) -> String;
```

## 3.3 阶段戳（transcript v0.2 增量字段）

transcript 文档新增一个可选字段 `stages`（格式规范 §18 的 0.2 版演进，向后兼容——
缺省即「从未跑过」）：

```jsonc
"stages": {
  "asr":       "1234:g1.0:g87.4:k3f9…",   // 内容指纹：转录完成时的文本
  "asrLayout": "…",                        // 版式指纹：breaks+paraBreaks+hidden 排序串
  "polish":    "…",                        // 内容指纹：润色提交时
  "segment":   "…",                        // 结构指纹（id）：分段提交时
  "chapters":  "…"                         // 内容指纹：章节提交时
},
"transSrc": {                              // lang → { sentenceId → 源文/可见词指纹 }
  "en": { "s-g1.0": "…", "s-g5.2": "…" }
}
```

脏检测规则表（谁写 / 谁读 / 何时过期）：

| 戳 | 指纹类型 | 过期条件 | 含义 |
| --- | --- | --- | --- |
| `asr` | 文本 | 当前文本 ≠ 戳 | 存在人工文本编辑（决定 `--polish` 默认值翻转） |
| `asrLayout` | 版式串 | 当前版式 ≠ 戳 | 存在人工分句/分段干预（自动分段让位于人工） |
| `polish` | 文本 | 当前文本 ≠ 戳 | 润色后又有编辑，润色过期 |
| `segment` | **id** | 当前 id 集 ≠ 戳 | 纯文本润色**不**使分段过期；重转录使其过期 |
| `chapters` | 文本 | 当前文本 ≠ 戳 | 章节标题可能与内容脱节 |
| `transSrc[lang][sentenceId]` | 单源项目为整句源词；时间线项目为 cut 后可见词序列 | 对应指纹变化或已有译文缺 stamp | **句粒度**过期——增量翻译的基础（§8.5） |

`segment` 用 id 指纹是整张表的点睛之笔：分段产物（`paraBreaks`）以词 id 为键，
润色靠 rebind 保住未改词的 id，所以「润色一遍」不会把分段作废；而重转录换发全部 id，
分段必然过期。**过期语义与产物键的锚定方式一致**，这是规则表能保持简单的原因。

## 3.4 项目包内的 AI 产物目录

依格式规范 §17 的项目包布局，新增 `ai/` 子目录（有价值、不可廉价重建——LLM 调用花钱，
故不放 `cache/`）：

```
myfilm.bcut/
  transcript.json                          主源规范文档（§18 + stages/trans/transSrc/transAlign）
  transcripts/<srcId>.json                 附加源规范文档（media.id = srcId）
  timeline.json                            可选：最终时间线与各源 cuts/clips
  ai/
    asr-rows.json            ASR 原始行（引擎原生 rows，审计与重建用）
    brief.json               文档简报：摘要 + 术语表 + 命名实体（§5.2）
    polish.json              润色产物：句记录 + 逐处修改建议（review 用）
    segment.json             分段产物：SegmentRecord[]（id+时间锚定）
    chapters.json            章节产物：fingerprint / rows / review / parts（分页运行记录）
    chapters/vNNN/           file-v1 页级尝试（pages/pNNN.*、outline.*、manifest.json）
    summary/                 写总结产物（§11.4）：vNNN/result.json + latest.json 指针
    blog/                    写博客产物（§11.4）：同上
    titles/                  起标题产物（§11.4）：同上
    *_status.json            断点续跑进度（完成即删）
  tasks/                     LLM agent 应答循环的契约与载荷（CLI 设计 §8）
```

除 ASR rows 外，可审计 AI 产物文件头部带 `fingerprint` 字段；读取方**必须**校验指纹后
才可使用。`ai/asr-rows.json` 沿用 speech-core 0.1 契约，不虚构 `fingerprint` 字段：其首个
生产读者以 `media.hash` 与主 transcript 的 `media.hash` 做同源校验，并要求词 id 仍是
`g<row>.<column>[~atom]` 结构；文件缺失、损坏、版本不识别或来源不适用时静默停用初始
软分段。完整契约见 [`bcut-asr-initial-segment-design.md`](../bcut-asr-initial-segment-design.md)。
译文的持久真相不另写 `sentences-<lang>.json`，而是各源 transcript 内的三张表；
`ai/*_status.json` 只承载可续现场，完成即删除。

## 3.5 断点续跑

```rust
// bcut-flow-core/src/progress.rs
pub struct PipelineStatus<T> {
    pub fingerprint: String,      // 输入词流指纹；不符直接作废
    pub total_pages: u32,
    pub processed_pages: u32,
    pub custom: T,                // 各阶段自定义：已提交段落 / 已译句 id 映射…
}
```

- 分页边界**不落盘**：从指纹化的词流确定性重导出（§5.3 的分页算法是纯函数）；
- 翻译的持久单位是**句 id 而非页号**（§8.4）——分页参数变化后续跑仍有效；
- 阶段完成必须删除 status 文件：完成态不留可续现场。
