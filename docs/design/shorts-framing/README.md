# docs/design/shorts-framing/ — 短视频的分屏同框

**一期已实现（2026-10-23）；二期设计已定、实现中（§11）**：横版的多人访谈剪成竖版短视频时，一个竖屏框装不下所有人的镜头（多人全景）把每个人各放一格、上下排开，其余镜头照旧对准一个人。建立在[产品设计 §5.10](../../product/product-design.md)「剪成短视频」「画面怎么取景」、[视频格式规范 §3.5](../../spec/video-format-spec.md#35-视觉坐标) 的取景点与[架构设计](../../architecture/architecture-design.md)的 `videos_derive` 之上，只写增加的部分。第 1–8 章是规则，第 9 章是平台差异，第 10 章验收，第 11 章分期。

原型：`designs/baocut` 的 `app/model-panels.js`（版式、格子与间距、区域换取景点、互换、放到上格、只留一人、在格子里缩放、接缝）、`app/stage-panels.jsx`（画布上的分格、滚轮与捏合缩放、属性面板「版式」段）、`app/model-shorts-cut.js` 的 `shots[].panels`（按镜头分段时哪几段分屏）、剪成短视频参数页的「跟着说话的人」「多人全景时分屏」与结果卡的版式条。单机位按说话人切段在 Runtime（§2.5），原型的演示结果仍按镜头给段，不模拟它。打开 `#/movie/p1?tab=aitools` 进剪成短视频，结果里的子视频打开后在画布上看分屏段。

## 1. 目标与范围

- 目标效果：竖版 9:16 成片里，原片是某个人的近景时画面对准这个人；原片切到多人全景时画面分成几格，每格一个人，同一支里每个人始终在同一格。版式只在原片的镜头切换处变化，不在一个镜头中间变。
- 不做：画中画式的小窗、格子之间的动画过渡、按说话人自动放大正在说话的那一格。分屏是取景的一种结果，不是一种转场。
- 适用：画幅不是保留原画幅（原片横、成片竖或方）且原片里同时有 2–4 个人；一个人或所有人都装得进一个竖屏框时不分屏。

## 2. 什么时候分屏

### 2.1 镜头分类：按相对大小，不按绝对面积

按 `videos_shots` 切出的每个镜头在中间取帧，用 `videos_frames` 的人脸框分类：

| 镜头 | 判定 |
| --- | --- |
| 单人近景 | 只有一张主脸；其余脸（若有）的面积不到最大那张的 1/4（背景里的人、屏幕上的人） |
| 多人全景 | 2 张以上主脸（面积不小于最大那张的 1/4），且它们的左右跨度（最左脸的左边到最右脸的右边）超过竖屏裁框宽 `cw` |
| 多人近景 | 2 张以上主脸，跨度不超过 `cw`：一个竖屏框装得下，按今天的规则取能装下所有人的最小框 |
| 没有人 | 一张脸也没有：插入的画面、屏幕录像，按今天的规则居中或对准画面主体 |

`cw = (画布宽 ÷ 画布高) × (原画高 × (1 − top − bottom) ÷ 原画宽)`（同 skill 今天的写法）。脸框的绝对面积只用来排除误检（小于 0.001 的不算），不再用一个固定阈值区分近景与全景：同一部片子的全景里，两张脸的面积可以都在 0.01 上下，与别的片子的近景差不多大。

### 2.2 多机位：跟着原片的镜头

原片有近景与全景来回切（多机位访谈）时：

- 版式只在原片的镜头边界上变：近景镜头一人，多人全景镜头分屏。成片里每次版式变化都落在原片本来就有的一刀上，不额外制造切换。
- **分屏段至少 3 秒**：短于 3 秒的多人全景不分屏，这一段对准说话的人（看不出谁在说时对准离画面中心最近的人）。相邻的两个多人全景镜头之间没有别的镜头（原片在两个全景机位之间切）时合并成一段算时长。门槛不再往上提：版式变化本来就落在原片的一刀上，原片自己的近景镜头也常有不到 3 秒的，3–4 秒的分屏段不比它们切得勤；提高门槛只会把这些全景裁成一个人，另一个人整段看不见。
- 一支里分屏段的格子顺序固定（§3.1），同一个人在每一段分屏里都在同一格。

### 2.3 单机位：跟着说话人，或整支分屏

原片只有一个固定的全景机位、所有人一直同框时，没有镜头边界可以跟。参数页取景选「跟着说话的人」（§8.1）时，按说话人在换人处造虚拟的镜头边界：谁在说就对准谁，两人抢着说或都不说话时分屏；选「自动」、或认不出谁是谁时，整支分屏。多机位的原片两种选法一样，跟着原片的镜头（§2.2）。

- **跟着说话人**：Runtime 先认出每个说话人是画面里的哪张脸（§2.5），再按转写逐词切成几段（`videos_shots` 的 `by: "speaker"`），每段对准一个人或分屏。规则依次是：
  1. 同一人前后两个词相隔不到 0.6 秒的连成一段话。两段话之间的停顿不超过 1.5 秒时并进前一段话；超过 1.5 秒的停顿（都不说话）自成一段，分屏。
  2. 连着 2 段以上的话、每段都短于 2 秒、而且换了人（两人在 2 秒内交替说话）：合成一段，分屏。
  3. 短于 1.5 秒的插话不换人：并进前一段（在最前面时并进后一段）。
  4. 认不出脸的说话人（§2.5）说话的那几段分屏：对不准人时宁可两个人都在。
  5. 相邻两段版式相同（同一个人，或都分屏）合并；短于 3 秒的段并进相邻的一段，相邻有分屏段时并进分屏段，否则并进较长的那段；直到每段都不短于 3 秒（整段本来就短于 3 秒时只有一段）。
- 参数页关掉分屏（§8.1）时，第 1、2、4 条该分屏的那几段改为留在前一段的人身上（在最前面时用后一段的人）；所有人都认不出时退回对准离画面中心最近的人。
- 原定的「同时笑」不做：转写里没有笑声的时间，靠画面认笑也不可靠。
- **为什么这里由 Runtime 定**：多机位的 3 秒门槛（§2.2）作用在一段里几个、十几个镜头上，智能体看得过来，所以是 skill 的规则（§5.2）；单机位的规则要逐词走完几百段话，交给模型既慢又容易数错，规则本身又是确定的、可以测。Runtime 只切段、说每段对准谁，每段的取景框与各格的区域仍由 skill 按 §3.2 与人脸框给。
- **整支分屏**（选「自动」，或跟不了时）：一个分屏段盖住整段，不按说话人来回切。一期就是这样：整支分屏不会对错人，也不闪。不改成整支对准主讲人：skill 认主讲人只看单人近景，单机位没有单人近景；两人 `rows` 每格的放大量（1.25–1.6）也不比把全景裁成一人（1.78）大（§3.3）。不要分屏的，在参数页关掉（§8.1）或在属性面板换回一人（§8.4）。
- **跟不了时退回整支分屏**：转写里不到 2 个说话人（没有转写、没识别说话人）、取样里多数帧不是同样 2–4 张主脸（不是单机位，或检测不到脸）、或谁也认不出（§2.5）时，`videos_shots` 以错误码拒绝（§2.5），skill 整支分屏，并在提示牌里说原因与怎么补（例如先在 AI 工具里识别说话人，再剪一次）。

### 2.4 不频繁切换

上面几条合起来保证：多机位时版式变化只发生在原片的镜头边界上；跟着说话人时只在换人处变，每段至少 3 秒，插话不换人；分屏段至少 3 秒；整支分屏时一支一个版式。参数页可以整个关掉分屏（§8.1），关掉时多人全景按今天的规则对准一个人。

### 2.5 说话人与脸的对应

`videos_shots` 给 `by: "speaker"`（缺省 `"picture"`，即按画面找切换）时，Runtime 认出转写里每个说话人是画面里的哪张脸，再按 §2.3 的规则切段。对应按素材算一次：取样在整份转写里挑，不只在要切的区间里，同一素材剪几支短视频时每个人对的是同一张脸；结果按素材版本与转写的修订缓存在 Runtime 内存里。skill 先按画面找切换（`by: "picture"`，§2.2），看出只有一个全景机位才改用 `by: "speaker"`，所以多机位的原片一般不付这一趟取样；Runtime 自己仍按取样里的脸数核对（下面的 `SHOTS_NOT_SINGLE_CAMERA`），不先整段解一遍画面找切换（那比取样还慢）。参数页关掉分屏时 skill 另给 `split: false`：§2.3 该分屏的段改为留在前一个人身上。

1. **取样**：只在一个人连续说了 4 秒以上的那段话里取（这段话的 30% 与 60% 处各一个），整份转写里均匀挑至多 48 个。
2. **每个取样看两样**：这一刻的一帧做人脸检测，主脸（同 §2.1：不小于最大那张的 1/4，面积不小于 0.001）按中心横坐标从左到右编号——单机位里人坐着不动，左右次序就是身份；再从这一刻起把 1.2 秒画面按每秒 12 帧、640 宽的灰度解出来，量每张脸嘴部（脸框高度的 62%–105%、宽度居中的 60%）相邻两帧的平均像素差。脸数与多数取样不同的、1.2 秒里整幅画面突变（相邻两帧整幅的平均差超过 25，即有一刀）的取样不用。
3. **对应**：每张脸的动静除以它在所有取样里的平均，消掉脸的大小、远近与光线的差别；按说话人求平均，得一张「说话人 × 脸」的表。在所有一一对应里取总分最大的那个（至多 4 人 4 张脸，穷举）。
4. **把握**：一个说话人的 `contrast` 是他对上的那张脸的分数 ÷ 他在别的脸上的最高分。取样不到 4 个、或 `contrast` 低于 1.25 的说话人认不出（`face` 为 null，§2.3 第 4 条）；一个也认不出时拒绝。`confidence` 是认出的说话人里最小的 `contrast`。
5. **实测**：一部双机位访谈里两人全景镜头的 40 个取样（主讲 34 个、采访者 6 个），表是主讲 [1.01, 0.66]、采访者 [0.92, 2.91]，两人都对，`contrast` 1.53 与 3.16；单看一个取样只有约八成认对，按说话人合起来才稳，所以门槛定在合起来的 `contrast` 上，不按单个取样投票。

返回（时间都是剪辑后时间线上的秒，同 `by: "picture"`）：

- `shots [{start, end, sampleAt, speaker, face}]`：每段对准的说话人 ID 与脸的编号，分屏段两项都是 null；`sampleAt` 同按画面切的镜头，用来核对。
- `faces [{box, speaker}]`：每张脸在所有取样里的中位框（`x`、`y`、`w`、`h` 按帧的宽高归一化，同 `videos_frames` 的 `faces`），按左右排；`speaker` 是认出的说话人，没人对上时 null。每段的取景框、分屏各格的区域都从这些框算（§3.2），不用再取帧。
- `speakers [{id, name, face, probes, contrast}]`、`confidence`、`detector: "mouth-motion"`；没有 `cuts`、`threshold`、`minShot`。
- 拒绝：`SHOTS_NO_SPEAKERS`（这个素材没有转写，或转写里不到 2 个说话人）、`SHOTS_NOT_SINGLE_CAMERA`（能用的取样不到 6 个，或不到七成的取样是同样 2–4 张主脸）、`SHOTS_SPEAKERS_UNMATCHED`（一个说话人也认不出）、`SHOTS_FACES_UNAVAILABLE`（人脸检测不可用）。`next` 都写退回整支分屏，`SHOTS_NO_SPEAKERS` 另写请用户先识别说话人；`SHOTS_NOT_SINGLE_CAMERA` 先写原片有近景与全景来回切时按画面的镜头取景（`by: "picture"`），整段确实只有一个全景机位时才整支分屏。
- 4K 原片 48 个取样约半分钟（每个取样解一帧与 1.2 秒画面），同一素材第二次起用缓存。

## 3. 版式与构图

### 3.1 人数与版式

格子是画布的百分比矩形，彼此不重叠；不留间距时铺满画布。人按在原片里从左到右的次序排进格子：

| 人数 | 版式 `layout` | 格子（9:16 画布，不留间距） | 每格的宽高比 |
| --- | --- | --- | --- |
| 2 | `rows` | 上下各一半：上 `0,0,100,50`，下 `0,50,100,50` | 9:8 |
| 3 | `rows`（缺省） | 三行等高：`0,0,100,33.333` / `0,33.333,100,33.334` / `0,66.667,100,33.333` | 27:16 |
| 3 | `spotlight`（上一下二） | 上格整宽 `0,0,100,50`；下面左右两格 `0,50,50,50`、`50,50,50,50` | 上 9:8，下 9:16 |
| 4 | `grid` | 田字格：左上、右上、左下、右下各四分之一 | 9:16 |
| 5 及以上 | 不分屏 | 对准说话的人；看不出时取能装下最多人的竖屏框 | — |

- 次序固定：最左边的人在最上面（`grid` 是左上），往右依次往下（`grid` 按左上、右上、左下、右下）。派生时按每格区域中心的横坐标排序（§5.2），智能体给的次序不影响结果。`spotlight` 例外：上格是指定的那个人（`main`，§5.1），另两人按左右放进下面两格。
- 方画幅（1:1）同样适用：`rows` 两格各 2:1，`grid` 各 1:1，`spotlight` 上格 2:1、下面各 1:1。横画幅成片（16:9 → 16:9）不分屏。
- 三人缺省用三行：三行不用知道谁是主讲，每个人的宽度一样。「上一下二」（`spotlight`）是可选版式，把主讲放大到上面整宽一格，另两人在下面各占半宽：要先定上格给谁，所以只在用户要（参数页的提示词里说了，或在属性面板换，§8.4）时用。四人的「上一下三」下面三格各 3:8，一格里看得见的原片又窄又高、人的头很小，不做。
- 三行的局限：格子扁（27:16），按 §3.2 放大到刚好装下区域的高度（约 4 张脸高）时，格子看得见约 7 张脸宽；三人并排坐、相邻两人的脸心相隔不到约 5 张脸宽时，邻座的肩膀会进格子边上。要切干净就得再放大，放大量会逼近 §3.3 的门槛；这种时候「上一下二」的下面两格（9:16）切得更干净。
- **间距** `gap`：格子之间留一条缝，宽度是画布短边的百分比（0–10，缺省 0；9:16 的 1080 宽画布上 1 是 10.8 像素），横缝竖缝一样宽（像素相同），只留在格子之间，贴画布边的一侧不留。格子按间距往里收（9:16 上三行留 2 时，竖缝高 2 × 1080 ÷ 1920 = 1.125%，三格是 `0,0,100,32.583` / `0,33.708,100,32.584` / `0,67.417,100,32.583`）；缝里露出下面的轨道，通常是序列的底色（缺省黑）。版式与间距合在一起由格子的矩形表达，格式里不另记（§4）。

### 3.2 每一格里怎么构图

智能体给的是每格「要看见的源区域」（四边比例，同 `crop`）：以这个人的脸为准，左右各留约一张脸宽，头顶留约半张脸高，向下到肩膀以下。派生把区域换成这一格的取景点与放大倍数：

- 这一格用 cover 铺满（原片按格子的宽高比裁），在铺满之上放大到刚好装下区域：`zoom = min(u₁ ÷ 区域宽, v₁ ÷ 区域高)`，`u₁`、`v₁` 是放大 1 倍时这一格看得见的源宽、源高（比例）；夹在 `[1, 4]`。
- 看得见的窗口（`u₁ ÷ zoom` × `v₁ ÷ zoom`）以区域中心为中心，碰到原片边缘时往里推；取景点 `x = 窗口左边 ÷ (1 − 窗口宽)`（窗口宽为 1 时取 0.5），`y` 同理。这与[视频格式规范 §3.5](../../spec/video-format-spec.md#35-视觉坐标) 的 `FocalPoint` 是同一个换算，只是「铺满」指铺满这一格而不是整个画布。
- 区域在放大 1 倍时都装不下（区域比这一格最宽的窗口还宽、还高）时，区域中心对准、多出的部分裁掉，派生给 `panel-region-cropped` 警告。

### 3.3 画质上限

每一格的放大量按「成片的一个像素对原片几个像素」算：`s × zoom`，`s = max(格宽 ÷ 源宽, 格高 ÷ 源高)`（像素）。1920×1080 原片剪 1080×1920 时：

| 版式 | `s` | 典型 `zoom` | 每格放大量 |
| --- | --- | --- | --- |
| 一人（整幅 9:16） | 1.78 | 1 | 1.78 |
| 两人 `rows` | 0.89 | 1.4–1.8 | 1.25–1.6 |
| 三人 `rows` | 0.59 | 2–2.5 | 1.2–1.5 |
| 三人 `spotlight` 上格 | 0.89 | 1.4–1.8 | 1.25–1.6 |
| 三人 `spotlight` 下面两格 | 0.89 | 1.6–2 | 1.4–1.8 |
| 四人 `grid` | 0.89 | 1.8–2.4 | 1.6–2.1 |

两人、三人分屏的放大量不比一人近景大；留间距时格子小一点，放大量跟着略小。任意一格超过 2.5 时派生给 `panel-upscaled` 警告：画面会发虚，智能体在提示牌里说，或改成不分屏。

## 4. 数据模型：`VideoItem.panels`

[视频格式规范 §3.4](../../spec/video-format-spec.md#34-实例item) 的 `VideoItem` 加一个可选字段：

```ts
interface VideoItem {
  // …既有字段
  panels?: VideoPanel[];               // 分屏：2–4 格；省略时一人（按 crop / focalPoint 取景）
}

interface VideoPanel {
  rect: { x: number; y: number; w: number; h: number };  // 画布百分比：左上角与宽高，[0, 100]
  focalPoint: FocalPoint;                                 // 这一格的取景点与放大（§3.5），「铺满」指铺满这一格
}
```

- 只用于 `mode: 'fullscreen'` 且 `fit` 为 `cover`（或省略）的视频实例；别的组合拒绝。格子 2–4 个，`w`、`h` 大于 0，矩形落在画布内、两两不重叠（可以贴边，也可以隔着缝）。版式与间距（§3.1）不另记：读回来时按格子的矩形认（认不出的是别处改过的格子，属性面板照样能调每格的取景，只是不显示版式与间距，§8.4）。
- 渲染：每一格画同一帧原片，先按实例的 `crop` 取源区域，再按这一格的 `focalPoint` 在格子里 cover，裁到格子之内；格子之外（间距）这件实例不画，露出下面的轨道。实例的 `focalPoint` 在有 `panels` 时不参与渲染（保留着，去掉 `panels` 时回到它）。不透明度与滤镜、效果对每一格同样生效（效果作用在每格的源画面上）；格子是固定的，实例的遮罩、翻转、入场 / 出场与循环动画、关键帧在分屏时不参与；转场把几格合成的整幅当作一个铺满画布的画面。
- 声音、时间映射、剪口、字幕投影都只看实例本身，与有几格无关。
- 编辑：`setStyle` 加 `panels`（数组整份替换；`null` 去掉）。一次改版式是一次 `setStyle`、一步撤销。

**为什么是一件实例里的几格，而不是几件画中画实例**：

- 同步：几格是同一帧，预览按实例 ID 共用一路解码，导出也只解一次；几件实例各自解码，拖动、变速时会差帧。
- 声音：一件实例一路内嵌音频；几件实例要静音其余几件，用户改音量时还得知道改哪件。
- 剪辑：剪口、剪辑集（§6.7）、字幕的 `scopeItemIds` 都按实例算；几件叠在不同轨上的实例部分重叠时剪辑集会拒绝（`scope-misaligned`），派生与剪口播都要额外对齐。
- 编辑：选中、拖入出点、删除、换素材都是一件；改成一人、互换上下是一次 `setStyle`。

## 5. 派生：`videos_derive` 的分屏段

### 5.1 输入

`crops` 的每一段可以是今天的单人裁剪，也可以是分屏：

```ts
type CropShot =
  | { from: number; to: number; left: number; top: number; right: number; bottom: number }   // 一人：同今天
  | { from: number; to: number; layout: 'rows' | 'grid' | 'spotlight'; panels: Crop[];       // 分屏：每格要看见的源区域
      main?: number;                                                                         // spotlight：panels 里放到上格的那一个（0 起）
      gap?: number };                                                                        // 格子间距：画布短边的百分比，0–10，缺省 0
```

- `rows` 要 2 或 3 格，`grid` 要 4 格，`spotlight` 要 3 格；格数不对、`spotlight` 没给 `main` 或越界、别的版式给了 `main` 时拒绝（`DERIVE_PANELS_INVALID`）。`gap` 超出 0–10 由参数校验拒绝。
- 分屏段只用于画幅变了、`fit` 为 cover 的派生；画幅不变或 `fit: 'contain'` 时分屏段按区域的并集当一人裁剪处理，给 `panels-ignored` 警告。

### 5.2 换算与落盘

- 格子按 §3.1 的版式、间距与画布尺寸生成；每格的区域按中心横坐标排序后依次放进格子（`grid` 按左上、右上、左下、右下）。`spotlight` 先把 `main` 那一格放进上格，其余两格按中心横坐标放进左下、右下。
- 区域按 §3.2 换成每格的 `focalPoint`；装不下时 `panel-region-cropped`（count 是格数），放大量超过 2.5 时 `panel-upscaled`（count 是格数）。
- 主素材的视频片段在取景变化的帧上拆开（同今天）：分屏段的片段写 `panels`、不写实例的 `crop` 与 `focalPoint`；单人段照旧写 `focalPoint`（及另一边的 `crop`）。相邻两段取景相同时不拆。
- 分屏段短于 3 秒时照样落盘，给 `split-short` 警告（count 是段数）：多机位的门槛是 skill 的规则，Runtime 只提醒；单机位跟着说话人切出的段由 `videos_shots` 保证不短于 3 秒（§2.3）。
- 派生来源文档的 `settings.crops` 记给的那一份（对到帧、截到区间之后），`framing` 记每段在主素材源时钟上的位置，分屏段多记 `layout` 与每格的 `rect`、`focalPoint`（`crop` 为 `null`）。分屏段数不另记：界面从 `settings.crops` 里带 `layout` 的段数出来。结果的 `framing` 同样带分屏段。`crops` 参与幂等键（同今天），分屏段的 `layout`、`panels`、`main` 与 `gap` 一并算进去（`gap` 为 0 与不给相同，`main` 只在 `spotlight` 时有）。

## 6. 剪成短视频 skill

`shorts-segments` 的「取景『自动』怎么做」按本文改写，「跟着说话的人」与它共用一套步骤，只在单机位时不同：

- 镜头分类用 §2.1 的相对规则；多机位按 §2.2，单机位按 §2.3。
- 单机位、提示词说跟着说话的人时：对这一段调 `videos_shots` 的 `by: "speaker"`（`range` 同按画面切），按返回的 `shots` 逐段给 `crops`——对准一人的段用这个人的脸框（`faces[face].box`）按今天单人近景的算法给裁框，分屏段用所有脸框按 §3.2 给各格区域；`from`、`to` 直接用 `shots` 的 `start`、`end`。拒绝时整支分屏，提示牌写原因（`SHOTS_NO_SPEAKERS` 时请用户先识别说话人再剪）。有说话人认不出（`face` 为 null）时在提示牌里说是谁、这几段为什么分屏。
- 每格区域的取法按 §3.2；格子次序交给 Runtime，不用自己排。三人默认 `rows`；用户要「上一下二」或「主讲在上面」时用 `spotlight`，`main` 给主讲那一格（主讲按 skill 认主讲人的规则定，认不出时问用户或用 `rows`）。用户要格子之间留缝时给 `gap`（说「留一条细缝」给 1–2）；不说不给。
- 参数页关掉分屏时（提示词里那一行说「不要分屏」），多人全景按今天的规则对准一个人。
- 结果的提示牌与交付说明写清哪几段分屏（例如「2 段上下分屏」），有 `panel-upscaled`、`split-short` 时如实说。
- 候选列表里「分屏或并排的双机位」仍是要说明的画面问题：那是原片里已经分好的画面，不是本文的分屏。

## 7. 字幕

- 分屏段里开始的字幕挂到接缝上：整块的中线落在两格相接处（9:16 两人时画布高的 50%，三行时取离字幕样式位置最近的那条），在这一句开始时决定，一句字幕中途不跳。一人段照字幕样式的位置（视频格式规范 §3.8）。规则写在[视频格式规范 §5.6](../../spec/video-format-spec.md#56-layoutprofile样式与导出)「Studio 样式在分屏段的摆放」，这里只写取舍：
  - **按句子自己的开始定，不按提前显示的时刻**：镜头切到全景通常正落在下一句开头，而字幕缺省提前半秒（`displayTiming.leadIn`）出现，按出现的时刻定会落在前一个一人镜头里，正该挂上去的那几句一句也挂不上。
  - **中线落在接缝，不是锚定的那条边**：底边钉在接缝上，两行字整块长在上一格人的胸口上；中线落在接缝时上下各占一点，上格是胸口、下格是头顶的留白。
  - **渲染时看，不写逐句样式**：做法同模板的字幕避让（[视频格式规范 §3.17](../../spec/video-format-spec.md#317-模板层) 的 `subsAvoid`），只挪位置，不改字号、宽度与底板；位置跟着片段当下的 `panels` 走，换回一人、改格子、整份重套字幕样式之后都不用补写 `cueStyles`。
- 格子之间留了间距（§3.1）时，接缝是缝的中线：上一格的下边与下一格的上边隔着不到画布高 10% 的缝、两格横向有重叠，就把缝的中线当接缝；字幕块正好压在缝上，上下两格各盖一点。
- 开关是 Studio 样式的 `panelSeam`，缺省开。属性面板字幕「位置」段有一行「分屏 · 挂到两格的接缝上」，序列里有分屏段、或这份样式已经关掉时才显示，免得关掉的状态看不见；智能体用 `setCaptionStyle` 的同名键。
- 在画布上拖动一句挂在接缝上的字幕：放下的地方就是用户要的位置，所以拖动同时关掉 `panelSeam`，按放下时字幕块的中线写 `y`（`verticalAlign` 写成 `center`，松手时不跳），一步撤销回来。起手按画出来的框量，不按样式里的 `y`：两者差着从底部到接缝的那一截。
- 双语字幕只拖其中一行：那一行写自己的位置（`origStyle` / `transStyle` 的 `x`、`y`），不再挂；另一行还挂在接缝上，变成一行独自居中在接缝上，会挪动半个行高。这是有意的：只拖一行时不关 `panelSeam`，否则这份样式里别的挂在接缝上的句子一起掉回样式的位置，动静更大；要两行一起走，两行一起选中再拖（同上一条，开关随之关掉）。

## 8. 确认与修改

### 8.1 参数页

「取景」一节（画幅不是保留原画幅时出现）：

- **跟着说话的人**（单选的一项，一期置灰）：说明「谁说话对准谁：原片有近景与全景来回切时跟着原片的镜头；只有一个全景机位时按说话人换人，两人抢着说或都不说话时分屏」。转写里分出 2 个以上说话人时可选，并且是缺省选中的一项；分不出时置灰，写「转写里还没分出说话人 · 先用「识别说话人」」，缺省回到「自动」。提示词里取景那一句写「跟着说话的人：有近景与全景来回切时按镜头取景；只有一个全景机位时用 videos_shots 的 by speaker 按说话人切段，谁说话对准谁」。
- **多人全景时分屏**（单选下面的开关，缺省开，选「自动」或「跟着说话的人」时出现）：「自动」时说明「原片切到几个人的全景、一个竖屏框装不下时，每人一格上下排开；只在镜头切换处换，短于 3 秒的全景不分屏」，「跟着说话的人」时说明「切到几个人的全景、两人抢着说或都不说话时，每人一格上下排开；每段至少 3 秒」。关掉时说明「几个人的全景也只对准一个人」。
- 提示词多一行：开着时「多人全景镜头分屏，每人一格」，关着时「不要分屏，多人全景也对准一个人」。

### 8.2 结果页

每张短视频卡的「取景」一行写段数与分屏段数（「5 段 · 2 段分屏」），下面一条**版式条**：按子视频时长画成一条横条，一人段与分屏段两种填色，分屏段上标格数（「2」）；悬停显示起止时间。点一段：这一支正在看时把编辑器的播放头移到这一段的开头；没在看时先打开这一支（从头开始，不跳到那一段）。点了不选中那一段片段：编辑器一选中片段，侧栏就换到属性页，结果页会被换走；要改这一段，在画布上点它。分屏段写进卡上的提示牌由智能体负责（§6），版式条由 Runtime 的派生记录画，两者不互相代替。

### 8.3 编辑器：画布

- 有 `panels` 的片段在画布上按格子画；选中时选中框是整个画布，格子之间画一条细的接缝线，每格角上标「上 / 下」（`grid` 标「左上」等）。
- 画布小牌（今天的「按原片取景」小牌）写「分屏 · 2 格」，旁边的 ⓘ 说明为什么不能拖动整件、去哪里改。
- 在一格里拖动：平移这一格的取景点（按住哪一格就只动哪一格），松手记一步撤销。画面不会被拖出格子，碰到原片边缘就停，并在小牌上提示「已经到原片边上了」。
- 在一格里缩放：选中分屏段后，指针在哪一格里，滚轮（含触控板双指滑动）或捏合（触控板捏合、触屏双指）就缩放哪一格。以指针下的那一点为中心：那一点对着的原片位置不动，碰到原片边缘时往里推；最小是铺满这一格（100%），最多 4 倍，到了下限、上限或边缘时小牌提示「最小是铺满这一格」「最多放大到 4 倍」「已经到原片边上了」。往上滚、两指张开是放大。一阵连续的滚动停下约 0.4 秒后记成一步撤销；属性面板这一格的「放大」「左右位置」「上下位置」跟着变。没选中分屏段时滚轮不做事，免得划过画布时误改。
- 分屏段没有缩放手柄，拖动不会把它改成自由摆放；工具栏的「适应画布」对它不起作用，点了提示分屏恒铺满、不能留边，要换回一人去属性面板的「版式」；「填满画布」本来就是现状，不做事。用方向键微移时同样只给一句提示，说明在格子里拖动或去属性面板调。

### 8.4 编辑器：属性面板「版式」段

有 `panels` 的片段，属性面板的「取景」段换成「版式」段；一人的、按原片取景的片段在「取景」段下面多一行「版式」：

- **版式**：分段控件「一人 / 分屏」。一人 → 分屏：按两格 `rows`，上格取原片左半、下格取右半（取景点 `x` 0.25 与 0.75，放大 1.4），之后在格子里调；分屏 → 一人：去掉 `panels`，回到实例原来的取景点；派生出来的分屏段没有自己的取景点，按上格（`grid` 是左上格）那个人对准。
- **格子**：每格一行，写「上」「下」（三行写「上 / 中 / 下」，`grid` 写「左上」等），各有「放大」「左右位置」「上下位置」三个数值。某格放大超过 2.5 倍（与派生的 `panel-upscaled` 同一个门槛）时，格名旁标「这一格放得太大，画面会发虚」。
- **格子**（三格时）：分段控件「三行 / 上一下二」。换的时候每格保留看得见的那块原片的中心与高度（放大夹在 1–4 倍里），人还是那几个人：上格的人仍在上格，中、下两格的人依次进左下、右下，反过来同理。格子是认不出的版式（别处改过的矩形）时不显示这一行与「间距」。
- **间距**：0–10（画布短边的百分比，§3.1），拖动时画面跟着变，松手记一步撤销；改间距时每格同样保留看得见的那块原片的中心与高度。
- 格名：三行写「上 / 中 / 下」，上一下二写「上 / 左下 / 右下」。
- **互换上下**（两格时）、**放到上格**（上一下二时，左下、右下两格各一项：和上格的人对调，各自保留看得见的那块原片）、**只留这一格的人**（每格一项：把这一格的取景换成整幅一人的取景点，人还在画面上原来的横向位置）。
- **套到整支**：把这一段的格子（版式、间距与各格的放大与位置）套到这支视频的其它分屏段，格数相同的才套；一人段不动。没有同格数的其它分屏段时不显示。一人段「取景」段里的「套到整支」也跳过分屏段。

所有改动都是 `setStyle`，撤销、重做与今天的取景一样；改动只影响这一段片段。切版式、换格子、改间距、互换、放到上格、只留一人、套到整支各记一步，切版式、互换、放到上格、只留一人、套到整支完成后给一条带「撤销」的提示。

## 9. 平台差异

- 画布分格、在格子里拖动与缩放、属性面板「版式」段在 Electron 与 Web 的编辑器都有（同一份 `packages/ui`），预览与导出用同一份帧计划（`crates/render-graph`），两边像素一致。
- 捏合：触控板捏合在 Electron 与浏览器里都以按着 Ctrl 的滚轮事件到达；浏览器里它本来会缩放整个网页，所以只在指针落在选中的分屏格里时拦下（`preventDefault`），别处照常。触屏的双指捏合走触摸事件，同样只在格子里拦。
- 参数页的「跟着说话的人」与开关、结果页的版式条只在 Electron：剪成短视频是 AI 工具，Web 没有 AI 工具 Tab（产品设计 §5.10）。`videos_shots` 的 `by: "speaker"` 在 Runtime 里，命令行与 MCP 同样能用。
- 分屏不涉及文件系统或系统集成，Windows 与 macOS 无差异。

## 10. 验收

- 帧计划：有 2 格 `panels` 的片段仍是一个视觉层，层上带 2 格（每格的矩阵与源区域，源区域等于按 §3.2 换算的窗口）；去掉 `panels` 时层上没有格子。
- 校验：`panels` 用在非全屏或 `contain` 的片段、格数不在 2–4、矩形越界或重叠时 `setStyle` 与读格式都拒绝。
- 派生：给分屏段时片段只在取景变化的帧上拆开；同一个镜头里不出现版式变化；格子次序按区域的横坐标，与给的次序无关；同样的输入两次调用认回同一个子视频。
- 声音：分屏段只有一路内嵌音频，导出的音轨与不分屏时逐样本相同。
- 字幕：分屏不改变子视频的字幕条数（`captions[].cueCount` 与同一区间不分屏时相同）。在分屏段开始的一句，整块的中线在接缝上，一直到这一句结束；开始在一人段、延续进分屏段的一句留在原处；提前显示的那一段已经在接缝上；关掉 `panelSeam` 时与不分屏时同一个位置；在画布上拖动一句挂在接缝上的字幕，松手的地方就是它的位置，开关随之关掉。
- 画质：`panel-upscaled` 只在某格放大量超过 2.5 时出现。
- 版式与间距：`spotlight` 的上格是 `main` 那一格、下面两格按区域的横坐标；`spotlight` 少给或多给 `main`、格数不对时拒绝；间距按画布短边算，横缝与竖缝像素相同，不留外边；读回来的格子认出原来的版式与间距，`gap` 为 0 时与一期的格子逐位相同。
- 接缝：留间距时字幕块的中线落在缝的中线上；左右并排、没有横缝的格子不挂。
- 缩放：滚轮与捏合以指针为中心缩放指针下那一格，夹在 1–4 倍，一阵滚动记一步撤销；没选中分屏段时滚轮不改任何东西；网页在格子里捏合不缩放整页。
- 说话人与脸：合成的取样（给定每张脸的嘴部动静）认出正确的一一对应；`contrast` 低于 1.25 或取样不到 4 个的说话人认不出；一个也认不出、不到 2 个说话人、多数取样不是同样几张脸时各以对应的错误码拒绝。
- 跟着说话人的规则：停顿超过 1.5 秒分屏、不超过的并进前一段；2 秒内交替的一串分屏；短于 1.5 秒的插话不换人；认不出的说话人那几段分屏；每段不短于 3 秒；关掉分屏时这些段留在前一个人身上；被剪掉的话不算，时间是剪辑后时间线的秒。
- 真实片子：一部双机位访谈（近景 + 两人全景）剪成 9:16，全景镜头 ≥ 3 秒的那几段是两格，其余是一人，版式变化都落在原片的镜头边界上。同一部片子的两人全景镜头连起来当单机位用 `by: "speaker"`：两人对上各自的脸，每段至少 3 秒，对准的是正在说的人。

## 11. 分期

- **一期**：两人、三人 `rows` 与四人 `grid` 的数据模型、渲染、派生与校验；skill 的相对分类、多机位跟镜头、单机位整支分屏；参数页开关；结果卡的段数与版式条；编辑器的画布分格与在一格里拖动平移、属性面板「版式」段（版式切换、每格放大与位置、互换、只留一人、套到整支）；分屏段字幕挂到接缝（§7）。
- **二期**：说话人与画面里的脸对应（`videos_shots` 的 `by: "speaker"`，§2.5）与参数页「跟着说话的人」（单机位按说话人换人，§2.3、§8.1）；在一格里用滚轮或捏合缩放（§8.3）；「上一下二」（`spotlight`）与格子间距，属性面板的「格子」「间距」「放到上格」，套到整支连格子一起套（§3.1、§8.4）；留间距时字幕挂在缝的中线（§7）。
- 不做：四人的「上一下三」（格子太窄，§3.1）；「同时笑」时分屏（§2.3）；多机位的全景里按说话人认脸（多机位跟着原片的镜头，两种选法一样）。
