# docs/design/shorts-framing/ — 短视频的分屏同框

**方案稿（2026-10-22）**：横版的多人访谈剪成竖版短视频时，一个竖屏框装不下所有人的镜头（多人全景）把每个人各放一格、上下排开，其余镜头照旧对准一个人。建立在[产品设计 §5.10](../../product/product-design.md)「剪成短视频」「画面怎么取景」、[视频格式规范 §3.5](../../spec/video-format-spec.md#35-视觉坐标) 的取景点与[架构设计](../../architecture/architecture-design.md)的 `videos_derive` 之上，只写增加的部分。第 1–8 章是规则，第 9 章是平台差异，第 10 章验收，第 11 章分期，第 12 章待评审事项。

原型：`designs/baocut` 的 `app/model-panels.js`（版式、格子几何、区域换取景点、互换与只留一人）、`app/stage-panels.jsx`（画布上的分格与属性面板「版式」段）、`app/model-shorts-cut.js` 的 `shots[].panels`（按镜头分段时哪几段分屏）、剪成短视频参数页的「多人全景时分屏」与结果卡的版式条。打开 `#/movie/p1?tab=aitools` 进剪成短视频，结果里的子视频打开后在画布上看分屏段。

## 1. 目标与范围

- 目标效果：竖版 9:16 成片里，原片是某个人的近景时画面对准这个人；原片切到多人全景时画面分成几格，每格一个人，同一支里每个人始终在同一格。版式只在原片的镜头切换处变化，不在一个镜头中间变。
- 不做：画中画式的小窗、格子之间的动画过渡、按说话人自动放大正在说话的那一格。分屏是取景的一种结果，不是一种转场。
- 适用：画幅不是保留原画幅（原片横、成片竖或方）且原片里同时有 2–4 个人；一个人或所有人都装得进一个竖屏框时不分屏。

## 2. 什么时候分屏

### 2.1 镜头分类：按相对大小，不按绝对面积

按 `videos_shots` 切出的每个镜头在中间取帧，用 `videos_frames` 的人脸框分类：

| 镜头 | 判定 |
| --- | --- |
| 单人近景 | 只有一张主脸；其余脸（若有）的面积不到最大那张的 1/4（背景里的人、屏幕上的人） |
| 多人全景 | 2 张以上主脸（面积不小于最大那张的 1/4），且它们的左右跨度（最左脸的左边到最右脸的右边）超过竖屏裁框宽 `cw` |
| 多人近景 | 2 张以上主脸，跨度不超过 `cw`：一个竖屏框装得下，按今天的规则取能装下所有人的最小框 |
| 没有人 | 一张脸也没有：插入的画面、屏幕录像，按今天的规则居中或对准画面主体 |

`cw = (画布宽 ÷ 画布高) × (原画高 × (1 − top − bottom) ÷ 原画宽)`（同 skill 今天的写法）。脸框的绝对面积只用来排除误检（小于 0.001 的不算），不再用一个固定阈值区分近景与全景：同一部片子的全景里，两张脸的面积可以都在 0.01 上下，与别的片子的近景差不多大。

### 2.2 多机位：跟着原片的镜头

原片有近景与全景来回切（多机位访谈）时：

- 版式只在原片的镜头边界上变：近景镜头一人，多人全景镜头分屏。成片里每次版式变化都落在原片本来就有的一刀上，不额外制造切换。
- **分屏段至少 3 秒**：短于 3 秒的多人全景不分屏，这一段对准说话的人（看不出谁在说时对准离画面中心最近的人）。相邻的两个多人全景镜头之间没有别的镜头（原片在两个全景机位之间切）时合并成一段算时长。
- 一支里分屏段的格子顺序固定（§3.1），同一个人在每一段分屏里都在同一格。

### 2.3 单机位：整支一个版式

原片只有一个固定的全景机位、所有人一直同框时，没有镜头边界可以跟。一期整支用分屏，不按说话人在一人与分屏之间来回切：

- 一期没有说话人与画面里哪张脸的对应（字幕面板的「跟随说话人」还没有模型），按说话人切一人会对错人；整支分屏不会错，也不闪。
- 二期有了说话人与脸的对应后，单机位可以选「跟着说话人」：在说话人换人处造虚拟的镜头边界，再按 2.2 的规则决定版式；插话短于 1.5 秒不换人，任何一段至少 3 秒；两人在 2 秒内交替说话、同时笑或都不说话超过 1.5 秒的那一段分屏（§11）。

### 2.4 不频繁切换

上面三条合起来保证：版式变化只发生在原片的镜头边界上；分屏段至少 3 秒；单机位一期一支一个版式。参数页可以整个关掉分屏（§8.1），关掉时多人全景按今天的规则对准一个人。

## 3. 版式与构图

### 3.1 人数与版式

格子是画布的百分比矩形，铺满画布、彼此不重叠、中间不留缝。人按在原片里从左到右的次序排进格子：

| 人数 | 版式 `layout` | 格子（9:16 画布） | 每格的宽高比 |
| --- | --- | --- | --- |
| 2 | `rows` | 上下各一半：上 `0,0,100,50`，下 `0,50,100,50` | 9:8 |
| 3 | `rows` | 三行等高：`0,0,100,33.333` / `0,33.333,100,33.334` / `0,66.667,100,33.333` | 27:16 |
| 4 | `grid` | 田字格：左上、右上、左下、右下各四分之一 | 9:16 |
| 5 及以上 | 不分屏 | 对准说话的人；看不出时取能装下最多人的竖屏框 | — |

- 次序固定：最左边的人在最上面（`grid` 是左上），往右依次往下（`grid` 按左上、右上、左下、右下）。派生时按每格区域中心的横坐标排序（§5.2），智能体给的次序不影响结果。
- 方画幅（1:1）同样适用：`rows` 两格各 2:1，`grid` 各 1:1。横画幅成片（16:9 → 16:9）不分屏。
- 三人用三行而不用「上一下二」：三行里每个人的宽度一样，没有谁被排成主角；「上一下二」留待二期作为可选版式（§12）。

### 3.2 每一格里怎么构图

智能体给的是每格「要看见的源区域」（四边比例，同 `crop`）：以这个人的脸为准，左右各留约一张脸宽，头顶留约半张脸高，向下到肩膀以下。派生把区域换成这一格的取景点与放大倍数：

- 这一格用 cover 铺满（原片按格子的宽高比裁），在铺满之上放大到刚好装下区域：`zoom = min(u₁ ÷ 区域宽, v₁ ÷ 区域高)`，`u₁`、`v₁` 是放大 1 倍时这一格看得见的源宽、源高（比例）；夹在 `[1, 4]`。
- 看得见的窗口（`u₁ ÷ zoom` × `v₁ ÷ zoom`）以区域中心为中心，碰到原片边缘时往里推；取景点 `x = 窗口左边 ÷ (1 − 窗口宽)`（窗口宽为 1 时取 0.5），`y` 同理。这与[视频格式规范 §3.5](../../spec/video-format-spec.md#35-视觉坐标) 的 `FocalPoint` 是同一个换算，只是「铺满」指铺满这一格而不是整个画布。
- 区域在放大 1 倍时都装不下（区域比这一格最宽的窗口还宽、还高）时，区域中心对准、多出的部分裁掉，派生给 `panel-region-cropped` 警告。

### 3.3 画质上限

每一格的放大量按「成片的一个像素对原片几个像素」算：`s × zoom`，`s = max(格宽 ÷ 源宽, 格高 ÷ 源高)`（像素）。1920×1080 原片剪 1080×1920 时：

| 版式 | `s` | 典型 `zoom` | 每格放大量 |
| --- | --- | --- | --- |
| 一人（整幅 9:16） | 1.78 | 1 | 1.78 |
| 两人 `rows` | 0.89 | 1.4–1.8 | 1.25–1.6 |
| 三人 `rows` | 0.59 | 2–2.5 | 1.2–1.5 |
| 四人 `grid` | 0.89 | 1.8–2.4 | 1.6–2.1 |

两人、三人分屏的放大量不比一人近景大。任意一格超过 2.5 时派生给 `panel-upscaled` 警告：画面会发虚，智能体在提示牌里说，或改成不分屏。

## 4. 数据模型：`VideoItem.panels`

[视频格式规范 §3.4](../../spec/video-format-spec.md#34-实例item) 的 `VideoItem` 加一个可选字段：

```ts
interface VideoItem {
  // …既有字段
  panels?: VideoPanel[];               // 分屏：2–4 格；省略时一人（按 crop / focalPoint 取景）
}

interface VideoPanel {
  rect: { x: number; y: number; w: number; h: number };  // 画布百分比：左上角与宽高，[0, 100]
  focalPoint: FocalPoint;                                 // 这一格的取景点与放大（§3.5），「铺满」指铺满这一格
}
```

- 只用于 `mode: 'fullscreen'` 且 `fit` 为 `cover`（或省略）的视频实例；别的组合拒绝。格子 2–4 个，`w`、`h` 大于 0，矩形落在画布内、两两不重叠（可以贴边）。
- 渲染：每一格画同一帧原片，先按实例的 `crop` 取源区域，再按这一格的 `focalPoint` 在格子里 cover，裁到格子之内。实例的 `focalPoint` 在有 `panels` 时不参与渲染（保留着，去掉 `panels` 时回到它）。不透明度、滤镜与效果、翻转、入场 / 出场动画、转场对每一格同样生效，各按自己的格子算。
- 声音、时间映射、剪口、字幕投影都只看实例本身，与有几格无关。
- 编辑：`setStyle` 加 `panels`（数组整份替换；`null` 去掉）。一次改版式是一次 `setStyle`、一步撤销。

**为什么是一件实例里的几格，而不是几件画中画实例**：

- 同步：几格是同一帧，预览按实例 ID 共用一路解码，导出也只解一次；几件实例各自解码，拖动、变速时会差帧。
- 声音：一件实例一路内嵌音频；几件实例要静音其余几件，用户改音量时还得知道改哪件。
- 剪辑：剪口、剪辑集（§6.7）、字幕的 `scopeItemIds` 都按实例算；几件叠在不同轨上的实例部分重叠时剪辑集会拒绝（`scope-misaligned`），派生与剪口播都要额外对齐。
- 编辑：选中、拖入出点、删除、换素材都是一件；改成一人、互换上下是一次 `setStyle`。

## 5. 派生：`videos_derive` 的分屏段

### 5.1 输入

`crops` 的每一段可以是今天的单人裁剪，也可以是分屏：

```ts
type CropShot =
  | { from: number; to: number; left: number; top: number; right: number; bottom: number }   // 一人：同今天
  | { from: number; to: number; layout: 'rows' | 'grid'; panels: Crop[] };                   // 分屏：每格要看见的源区域
```

- `rows` 要 2 或 3 格，`grid` 要 4 格；格数不对时拒绝（`DERIVE_PANELS_INVALID`）。
- 分屏段只用于画幅变了、`fit` 为 cover 的派生；画幅不变或 `fit: 'contain'` 时分屏段按区域的并集当一人裁剪处理，给 `panels-ignored` 警告。

### 5.2 换算与落盘

- 格子按 §3.1 的版式与画布尺寸生成；每格的区域按中心横坐标排序后依次放进格子（`grid` 按左上、右上、左下、右下）。
- 区域按 §3.2 换成每格的 `focalPoint`；装不下时 `panel-region-cropped`（count 是格数），放大量超过 2.5 时 `panel-upscaled`（count 是格数）。
- 主素材的视频片段在取景变化的帧上拆开（同今天）：分屏段的片段写 `panels`、不写实例的 `crop` 与 `focalPoint`；单人段照旧写 `focalPoint`（及另一边的 `crop`）。相邻两段取景相同时不拆。
- 分屏段短于 3 秒时照样落盘，给 `split-short` 警告（count 是段数）：门槛是 skill 的规则，Runtime 只提醒。
- 派生来源文档的 `settings.crops` 记给的那一份（对到帧、截到区间之后），`framing` 记每段在主素材源时钟上的位置，分屏段多记 `layout` 与每格的 `rect`、`focalPoint`；`summary` 加 `splits`（分屏段数）。结果的 `framing` 同样带分屏段。`crops` 参与幂等键（同今天），分屏段的 `layout` 与 `panels` 一并算进去。

## 6. 剪成短视频 skill

`shorts-segments` 的「取景『自动』怎么做」按本文改写：

- 镜头分类用 §2.1 的相对规则；多机位按 §2.2，单机位按 §2.3。
- 每格区域的取法按 §3.2；格子次序交给 Runtime，不用自己排。
- 参数页关掉分屏时（提示词里那一行说「不要分屏」），多人全景按今天的规则对准一个人。
- 结果的提示牌与交付说明写清哪几段分屏（例如「2 段上下分屏」），有 `panel-upscaled`、`split-short` 时如实说。
- 候选列表里「分屏或并排的双机位」仍是要说明的画面问题：那是原片里已经分好的画面，不是本文的分屏。

## 7. 字幕

- 一期字幕位置不随版式变：字幕样式决定位置（视频格式规范 §3.8），分屏段与一人段用同一个位置。两人 `rows` 时默认的底部字幕落在下面那一格的胸口一带，不挡脸。
- 二期：分屏段里开始的字幕挂到两格的接缝上（9:16 两人时画布高的 50%），在字幕开始时决定，一句字幕中途不跳。机制是样式的逐句覆盖 `cueStyles[句子 ID].source.y`（字幕渲染已经支持逐句改位置）；要解决的是字幕样式由后面的步骤整份套用时逐句覆盖不能被冲掉（§12）。

## 8. 确认与修改

### 8.1 参数页

「取景」一节（画幅不是保留原画幅时出现）在单选下面加一个开关：

- **多人全景时分屏**（缺省开）：说明「原片切到几个人的全景、一个竖屏框装不下时，每人一格上下排开；只在镜头切换处换，短于 3 秒的全景不分屏」。关掉时说明「几个人的全景也只对准一个人」。
- 提示词多一行：开着时「多人全景镜头分屏，每人一格」，关着时「不要分屏，多人全景也对准一个人」。

### 8.2 结果页

每张短视频卡的「取景」一行写段数与分屏段数（「5 段 · 2 段分屏」），下面一条**版式条**：按子视频时长画成一条横条，一人段与分屏段两种填色，分屏段上标格数（「2」）；悬停显示起止时间。点一段把编辑器的播放头移到这一段的开头（这一支没在看时先打开它）。分屏段写进卡上的提示牌由智能体负责（§6），版式条由 Runtime 的派生记录画，两者不互相代替。

### 8.3 编辑器：画布

- 有 `panels` 的片段在画布上按格子画；选中时选中框是整个画布，格子之间画一条细的接缝线，每格角上标「上 / 下」（`grid` 标「左上」等）。
- 画布小牌（今天的「按原片取景」小牌）写「分屏 · 2 格」，旁边的 ⓘ 说明为什么不能拖动整件、去哪里改。
- 在一格里拖动：平移这一格的取景点（按住哪一格就只动哪一格），松手记一步撤销。画面不会被拖出格子，碰到原片边缘就停，并在小牌上提示「已经到原片边上了」。放大在属性面板里调。

### 8.4 编辑器：属性面板「版式」段

有 `panels` 的片段，属性面板的「取景」段换成「版式」段；一人的、按原片取景的片段在「取景」段下面多一行「版式」：

- **版式**：分段控件「一人 / 分屏」。一人 → 分屏：按两格 `rows`，上格取原片左半、下格取右半（取景点 `x` 0.25 与 0.75，放大 1.4），之后在格子里调；分屏 → 一人：去掉 `panels`，回到实例原来的取景点。
- **格子**：每格一行，写「上」「下」（三行写「上 / 中 / 下」，`grid` 写「左上」等），各有「放大」与「左右位置」两个数值；`rows` 的格子还有「上下位置」。
- **互换上下**（两格时）、**只留这一格的人**（每格一项：把这一格的取景换成整幅一人的取景点，人还在画面上原来的横向位置）。
- **套到整支**：把这一段的格子取景（各格的放大与位置）套到这支视频的其它分屏段，格数相同的才套；一人段不动。

所有改动都是 `setStyle`，撤销、重做与今天的取景一样；改动只影响这一段片段。

## 9. 平台差异

- 画布分格、属性面板「版式」段在 Electron 与 Web 的编辑器都有（同一份 `packages/ui`），预览与导出用同一份帧计划（`crates/render-graph`），两边像素一致。
- 参数页的开关、结果页的版式条只在 Electron：剪成短视频是 AI 工具，Web 没有 AI 工具 Tab（产品设计 §5.10）。
- 分屏不涉及文件系统或系统集成，Windows 与 macOS 无差异。

## 10. 验收

- 帧计划：有 2 格 `panels` 的片段产生 2 个视觉层，各自裁到格子里，层的源区域等于按 §3.2 换算的窗口；去掉 `panels` 回到一层。
- 校验：`panels` 用在非全屏或 `contain` 的片段、格数不在 2–4、矩形越界或重叠时 `setStyle` 与读格式都拒绝。
- 派生：给分屏段时片段只在取景变化的帧上拆开；同一个镜头里不出现版式变化；格子次序按区域的横坐标，与给的次序无关；同样的输入两次调用认回同一个子视频。
- 声音：分屏段只有一路内嵌音频，导出的音轨与不分屏时逐样本相同。
- 字幕：分屏不改变子视频的字幕条数（`captions[].cueCount` 与同一区间不分屏时相同）。
- 画质：`panel-upscaled` 只在某格放大量超过 2.5 时出现。
- 真实片子：一部双机位访谈（近景 + 两人全景）剪成 9:16，全景镜头 ≥ 3 秒的那几段是两格，其余是一人，版式变化都落在原片的镜头边界上。

## 11. 分期

- **一期**：两人、三人 `rows` 与四人 `grid` 的数据模型、渲染、派生与校验；skill 的相对分类、多机位跟镜头、单机位整支分屏；参数页开关；结果卡的段数与版式条；编辑器的画布分格与在一格里拖动平移、属性面板「版式」段（版式切换、每格放大与位置、互换、只留一人、套到整支）。
- **二期**：说话人与画面里的脸对应（单机位「跟着说话人」，§2.3）；分屏段字幕挂到接缝（§7）；在一格里用滚轮或捏合放大；「上一下二」等可选版式与格子间距。
