# docs/design/version-history/ — 视频的版本记录

不依赖 git 的版本记录。每部视频在自己的目录里保存两样文本：

- **最新快照**：当前状态，行稳定的排版；
- **最近版本**：最近 10 个版本，每个是一份 unified diff，开头列出这一版的操作。

按版本回滚靠这串 diff。`video.db` 仍是唯一的权威（[架构设计 §5.1](../../architecture/architecture-design.md#51-存储分层)），快照与版本是派生物。项目在 git 仓库里时，快照随时可以提交。
