# docs/design/bot-mode/ — Bot 模式

给智能体加一种「长期在岗」的用法：用户按主题建频道，每个频道只有一条持续的对话；智能体在对话里接活，把耗时的活交给后台线程，每件活记成一条有状态的任务，并主动提出建议任务、按时跑周期任务、在对话里给出可点的提示。它建在现有的会话、Task、Job、完成收件箱、定时任务与工具桥之上（[架构设计 §3](../../architecture/architecture-design.md#3-agent-harness)、[§7.2](../../architecture/architecture-design.md#72-任务规格与应用记录)），不另起智能体引擎。
