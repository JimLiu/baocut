# 5. 共享语义：`bcut-editor-core::cut_mode`

> 出自 [BaoCut 剪口播技术方案（原型第 192–197 轮 → 内核 / serve / App v2 / Web）](../bcut-talking-head-cut-design.md)

新模块 `core/crates/bcut-editor-core/src/cut_mode/`，纯函数、无 I/O，`#![forbid(unsafe_code)]`，受既有纯度门禁扫描。

## 5.1 标记投影 `CutMarks` 与段内 token

```rust
pub enum CutMark { Cut { cut_id: String, category: String, removed_sec: f64 },
                   Suggested { item_id: String, category: String, removed_sec: f64 },
                   Pause { item_id: Option<String>, cut_id: Option<String>, gap_sec: f64, keep_sec: f64 } }
/// 只有标记，不复制词表：七小时项目十几万词的第二副本内核付不起（paras.rs 头注同一纪律）。
pub struct CutMarks { pub words: BTreeMap<String /*word_id*/, CutMark>, pub pauses_after: BTreeMap<String, CutMark> }
pub fn marks(cuts: &CutSet, provenance: &CutProvenance, review: Option<&CleanupReview>, words: &[WordTiming]) -> CutMarks
/// 单段的 token 切分，按可视行惰性调用；字节区间来自既有 subtitle_list::word_ranges。
pub struct CutToken { pub word_id: String, pub byte_range: Range<usize>, pub utf16_range: Range<u32>, pub t0: f64, pub t1: f64, pub cue: usize }
pub fn para_tokens(text: &str, words: &[CueWord]) -> Vec<CutToken>
pub fn token_at(text: &str, words: &[CueWord], byte_offset: usize) -> Option<usize>   // = transcript_list::word_index_at_byte_offset
```

- **token 就是 `words[]`**：ASR 的中文词已是逐字或短词，英文按词，标点跟前一个词——与原型 `tokens(text)` 同口径，但不再按字符比例折算时间；中文多字词一律不拆（`words[]` 是唯一真相，拆了没有时间）。`para_tokens` 同时给字节区间（GPUI `StyledText` 用）与 UTF-16 区间（Web DOM 用），转换本身进 fixture。
- **已剪标记**：`CutSet::word_is_cut(t0, t1)`（唯一入口，`edits::cut_word_ids` 已是它的调用方）→ `Cut`，`cut_id` 取 `cut_end_containing`；`category` 从 `ai/cuts.json` 取，没有则 `manual`。
- **建议标记**：`effective_state == pending` 的条目按 `wordIds`（`firstWordId..lastWordId` 在 `words[]` 里的闭区间）标 `Suggested`；`category == pause` 的条目不标字，写进 `pauses_after[afterWord]`。
- **已剪的停顿**：`entries[].kind == silence` 的 cut 也进 `pauses_after`（`◷ 1.4s` 小标划掉态）。

## 5.2 选区 `CutSelection` 与时间轴同步

```rust
pub struct CutSelection { pub src_id: String, pub first: String, pub last: String, pub live: bool }
pub struct CutSelectionSpan { pub source_start: f64, pub source_end: f64, pub fragments: Vec<MappedEvent>,
                              pub duration: f64, pub label: String /* "1.9s · 00:07.1 – 00:09.1" */ }
pub fn selection_span(sel: &CutSelection, words: &[WordTiming], duration: f64, fps: f64, map: &TimelineMap) -> Result<CutSelectionSpan, CutModeError>
```

- `first/last` 由视图的拖选命中给出（按 `words[]` 顺序归一化，跨段落允许，跨说话人允许）。
- 源区间 = `resolve_word_span(words, first, last, duration, fps, DEFAULT_WORD_PAD, DEFAULT_WORD_PAD)`——与 `cutWords` op **同一函数**，所以工具条上显示的时长就是将要剪掉的时长。
- 时间轴片段 = `map.clamp_source_event(src, start, end)`；跨已剪段时 `fragments.len() > 1`，高亮画多块，标签取 `duration = Σ fragments` 与首块起 / 末块止的时码。
- 时码格式 `mm:ss.d`（与 transport 一致），时长格式复用原型 `label(secs)`（`0.8s` / `1 分 12 秒`）。
- 选区与 `SelectionSet`（元素选中）互斥：`cut_mode::on_pick_element` 清选区；`SelectionSet` 非空时进剪辑模式先清元素选中。互斥规则写在核心，两端只转发事件。

## 5.3 动作、键位与工具条状态机

```rust
pub enum CutAction { CutSelection, AuditionSelection, ClearSelection,
                     AcceptItem(String), DismissItem(String), AuditionItem(String), RestoreCut(String), AuditionCut(String),
                     AcceptAll, DismissAll, RestoreAll, Rescan }
pub enum CutOp { TimelineOps(Vec<Value>), Review { action: ReviewAction, items: Vec<String> }, Audition { source_start: f64, source_end: f64 }, None }
pub fn resolve(action: CutAction, marks: &CutMarks, sel: Option<&CutSelection>, review: Option<&CleanupReview>) -> CutOp
pub fn toolbar(sel: Option<&CutSelection>, span: Option<&CutSelectionSpan>, scrolled_out: bool) -> Option<Toolbar>
pub fn key_predicate(key: &Chord, ctx: &CutKeyContext) -> Option<CutAction>
```

- `CutSelection` → `TimelineOps([cutWords {srcId, first, last}])`；`AcceptAll` → `Review { accept, items: 全部 effective pending }`；`RestoreAll` → `TimelineOps([restoreCut …])` 一批（一次请求 = 一条 journal 条目 = 一次 ⌘Z）。
- 键位并入 [`bcut-editor-interaction-port-design.md`](../bcut-editor-interaction-port-design.md) §2.8 的抽象动作表：`⌫ / Delete` 有 `CutSelection` 时 = `CutSelection`（捕获阶段，抢在删元素之前；无选区放行），`Esc` = `ClearSelection`，`⌘↵` = `AcceptAll`，`Space` 有选区时 = `AuditionSelection`。
- 工具条：`live`（拖选进行中）不出；`scrolled_out`（选区第一行离开可视区）收起；内容 = `span.label` + 剪掉 / 试听 / 取消。
- 汇总条三态文案（§13.1）由 `summary_text(marks, review, view_duration) -> SummaryBar` 生成：有建议 →「N 处建议 · 共 X ／ 口癖 a 处、停顿 b 处、重复起句 c 处 [· 另有 M 处已剪]」；没建议但剪过 →「已剪掉 N 处 · 成片 m:ss ／ 省下 X」；都没有 →「拖选一段文字，按 ⌫ 剪掉」。`view_duration` 来自 `CutSet::view_duration()`。

## 5.4 时间轴投影：缝标记与建议段

```rust
pub struct SeamMarker { pub cut_id: String, pub timeline_time: f64, pub removed_sec: f64, pub category: String }
pub struct SuggestedSeg { pub item_id: String, pub timeline_start: f64, pub timeline_end: f64, pub category: String }
pub fn timeline_overlay(cuts: &CutSet, provenance: &CutProvenance, review: Option<&CleanupReview>, map: &TimelineMap) -> (Vec<SeamMarker>, Vec<SuggestedSeg>)
```

- 缝标记时间 = `map.source_to_timeline(cut.t0, SeamBias::Preceding)`；相邻缝在 `CUT_MERGE_GAP` 内已被内核合并，不会重叠。
- 建议段 = `clamp_source_event(item.t0, item.t1)` 的片段（建议未生效，时间仍在，一般只有一块）。
- App v2 `cutseg.rs` 的输入从 `CutReview` 换成这两张表，同时修掉它直接拿时间轴 `Scale` 画源时钟 `t0/t1` 的既有缺陷（§2.5）；Web `ClipsRow` 新画。两端只拿到时间轴秒，不再各自换算。
- **落地命名（2026-09-07）**：两张表合成 `CutOverlay { seams, suggested }`；裁切 / 倍速 / 重复 clip 后的投影走 `mapped_timeline_overlay`（按实际 clip 逐次投影，App / Web 共用）。第 197 轮的「贯穿所有轨 + 折叠 + 展开」在其上再加一层 `fold_view(overlay, expanded) -> FoldView { seams: Vec<SeamGroup>, slots: Vec<CutSlot>, removed_total }`：同一时间轴位置相邻的缝并成一道 `SeamGroup`（标尺角标 `−N.Ns`、title 汇总类目、点 = 整道恢复），`expanded` 时给出 `CutSlot` 空槽带（源时长撑开、贯穿所有轨）。App 消费方是 `timeline/cutbands.rs`（取代 `cutseg.rs`）；Web 尚未接 `fold_view`（§15）。
- **拖空槽带边缘改范围（2026-10-01，`1.303.0`）**：`SeamMarker` / `CutSlot` 多带剪口的 `src_id / t0 / t1`（源时钟）与所在 clip 的 `rate`。纯函数 `drag_cut_edge(cuts, words, cut_id, CutEdge::{Start,End}, source_time, snap, fps, duration) -> Option<(t0, t1)>`：缺省吸到词边界，候选与 `cutWords` 同一套（左缘 `word_span_start`、右缘 `word_span_end`，带 `DEFAULT_WORD_PAD` 与帧对齐，隐藏词不出候选，没词或界内无候选退回自由）；Alt 自由按帧对齐；夹到 `[0, duration]`、不越相邻剪口（贴边可以）、至少一帧宽，拖过界贴住界。表面入口 `drag_slot_edge(slot, cuts, words, edge, press_x, x, pxps, free, fps, duration) -> Option<CutEdgeDrag>`：源时刻 = 原边 + `(x − press_x) / pxps × slot.rate`，预览只平移被拖的那条边（`start' = start + (t0' − t0) / rate`，右缘对称），`changed` 时带 `action = CutAction::RetimeCut {id, t0, t1}`，`resolve` 成 `TimelineOps([retimeCut])`（剪口不在或区间没变 → `None`）；按下没动原样返回。`FoldView::slot(cut_id)` 取第一条同 id 的带（缝恰在两段主轨 clip 交界时会投出两条）。wasm `cutModeDragEdge(input, {cutId, edge, pressX, x, pxps, alt})`。
- **compose 碎片回到自己的轨（第 196 轮裁决）**：内核 compose 把脱离的主视频 clip 按 `clips[].segments` 切成 `video-<clip>-<n>` 碎片元素；`timeline_doc::compose_groups()`（`ComposeGroup { track_id, clip_id, source_id, element_ids, start, end, src_start }`）把同一 clip 的全部碎片重新归组到**该 clip 自己的轨**，两端显示为一块、缝仍由 `cut_mode` 画，不新增「主视频」行（`COMPOSE_EPS = 1e-3`）。

## 5.5 试听窗口
