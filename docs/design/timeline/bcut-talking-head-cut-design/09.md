# 9. 播放、试听与导出

> 出自 [BaoCut 剪口播技术方案（原型第 192–197 轮 → 内核 / serve / App v2 / Web）](../bcut-talking-head-cut-design.md)

## 9.1 播放

已剪段折叠由既有 `TimelineMap::playback_step / next_position` 处理，播放头进已剪段直接跳到段尾——无改动。建议段不影响播放（不在 `cuts[]`）。

## 9.2 试听（C-R9）

试听要「把将要剪掉的那一截听一遍」，因此必须按**源时钟**播且**不折叠**。两端播放器加一个一次性模式 `audition(source_start, source_end)`：seek 到 `audition_window` 起点、播到止点即停、期间 transport 时码显示源时间并带「试听」徽标、结束后播放头回到进入前的时间轴位置。字幕叠加在试听期间按源时间投影（`render_source_subtitles` 同一口径），不走折叠。

## 9.3 导出

`sources[].cuts[]` 已被 `timeline_media::build_plan`、`bcut-editable::build_main_segments`、字幕 `clamp_source_event` 全部消费，建议不导出——无改动。`--no-cuts` 逃生口不变。剪缝音频硬拼接见 §11。
