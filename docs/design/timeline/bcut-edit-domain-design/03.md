> 移植自 BaoCut v2；文中的数据模型名（timeline.json、Element、Source / Clip / Cut 等）指 v2 的模型，与 v3 序列、轨道、实例的对应见[元素模型对照](../element-model-mapping.md)与[架构设计 §14](../../../architecture/architecture-design.md#14-待评审事项)。

# 3. timeline.json 数据模型

> 出自 [BaoCut 剪辑域协议设计（Cut / Clip / 元素 / 水印 / 工程导出）](../bcut-edit-domain-design.md)

## 3.1 顶层结构

```jsonc
{
  "bcutTimeline": "0.1",
  "sources": { /* §3.2 源表：媒体身份 + 源内 cuts + 转录归属；主媒体保留 id "main" */ },
  "clips":   [ /* §3.4 时间轴编排序列，数组序即时间轴 */ ],
  "tracks":  [ /* §3.6 叠加轨（elements） */ ],
  "main":    { /* §3.8 主画面变换与画布填充 */ }
}
```

- 全文档没有任何字段接受代码；值只有字面量与 §3.5 词锚点字符串（复用 BCF TimeExpr 的 `~` 子集）。
- **没有顶层 cuts 表**：剪切是源的内部状态（决策 10），生命周期与源绑定。
- 缺省最小合法文档是 `{"bcutTimeline":"0.1"}`：源无 cuts = 视图即原片，无 clips = 隐式单 clip 覆盖主媒体全视图。首次产生剪辑意图时由实现播种显式单 clip（`[{"id":"c1","in":0,"out":<duration>}]`）。**纯文稿剪辑工作流只在源上写 cuts，可以永远不碰 `clips`**——单 clip 引用整个视图，剪切自动折叠。

## 3.2 sources 表：媒体身份 + 源内 cuts + 转录归属

```jsonc
"sources": {
  "main": {                              // 保留 id：媒体身份仍由 project.json 持有，
    "cuts": [                            //   此条目只承载剪辑域的源状态（无身份字段）
      { "id": "cut-1", "t0": 12.40, "t1": 13.10, "ref": "cut-1" },   // ref → ai/cuts.json
      { "id": "cut-2", "t0": 47.02, "t1": 47.31 }
    ]
  },
  "src-a1": {
    "path": "media/broll/factory.mp4",   // 项目相对或绝对路径
    "hash": "sha256-…",
    "kind": "video",                     // video | image | audio
    "duration": 12.4,                    // image 省略
    "naturalW": 1920, "naturalH": 1080,
    "hasAudio": true,
    "poster": "cache/posters/src-a1.jpg",// 可重建，可省略
    "cuts": [ { "id": "cut-3", "t0": 0.0, "t1": 1.2 } ]
  }
}
```

- **源是剪辑域的聚合根**：一个源条目 = 媒体身份 + 源内 `cuts[]` + 转录归属。源被删除时，其 cuts 随条目一起消失（这正是 cuts 内聚的理由，决策 10）；引用它的 clip/元素随即触发 `clip-source-missing` error——删源是显式破坏性操作，命令面要求 `--yes` 并列出受影响对象；
- `"main"` 是保留条目：**身份字段（path/hash/kind/…）禁止出现**（单一来源仍在 `project.json.media`），只承载 `cuts` 等剪辑域源状态；无剪辑状态时条目可省略；
- 附加源 `hash` 语义与 `project.json` 一致（内容锚，变更使相关派生 stale）；
- **转录归属于源、物理文件分离**：`main` → 项目根 `transcript.json`，附加源 → `transcripts/<srcId>.json`（bcutTranscript 0.3，`media.id = srcId`），路径是协议约定、不落盘字段。转录内的词戳、`trans`/`transAlign`/`transSrc` 译文表全部锚**真实源时间/源词**，跟着源走——素材被剪、拼接、复用、换位，转录与译文一个字都不失效。删源后遗留的孤儿转录文件由 `project repair` 清理（明示、不静默）。无转录合法（此时该源没有词驱动剪切与视图字幕，仅时间区间剪切）。

## 3.3 媒体层：源内 `cuts[]`（无损假删除）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 文档内唯一，`cut-<n>` 确定性递增，一经分配不复用 |
| `t0` / `t1` | number | **源时间**区间，`0 ≤ t0 < t1 ≤ 源时长` |
| `ref` | string | 溯源条目 id（§3.9），可省略 |

规范约束与语义：

1. **每源各自一个集合**：按 `t0` 排序、互不重叠；0.02s 内相邻区间在写入时自动合并（合并后保留较早 id，被并 id 废弃不复用）。
2. **假删除**：条目存在即"剪掉"；`restore` = 删除条目。集合本身就是无损事实——不需要"kept 分区"陪衬，kept 是补集派生。
3. **词驱动写入**：`cut add --words wA..wB` 先按 [§18.6 WordSpan 规则](../../bcf/baocut-format-spec.md)把词区间落定为源时间区间（呼吸垫 `padPre/padPost = 0.05s`、不越相邻词、帧网格对齐——规范已定义，本协议是其首个实现），再写条目，回执标注 `snapped: true`。静音剪切直接按源时间区间写入（检测参数沿用老版：`threshold 0.8 / compressTo 0.3 / maxGap 3.0` 等，§5.1）。
4. **词的剪切状态是派生量**：词中点 `(t0+t1)/2` 落入其所属源的某 cut 区间（半开 `[t0, t1)`）⇒ 该词被剪。该判定的唯一实现入口是 `CutSet::word_is_cut`——锚点求值、投影、翻译可见词一律走它，禁止各处内联复制。`hidden` 覆盖表继续只管"不出字幕"（口误、语气词），二者语义独立、可叠加。
5. **媒体视图**由 cuts 唯一决定（§2.3）：视图时长、视图字幕（剪掉 cut 词、词戳换算为视图时间）、`viewTime/srcTime` 映射。视图是**纯派生**，任何实现按同一集合必须得到逐位一致的视图。

## 3.4 时间轴层：clips（编排、真删除）

```jsonc
"clips": [
  { "id": "c1", "in": 0.0,  "out": 48.00 },                    // 主媒体（srcId 缺省 "main"）
  { "id": "c2", "srcId": "src-a1", "in": 2.0, "out": 8.0 },    // 插入附加素材
  { "id": "c3", "in": 48.00, "out": 96.50 }                    // 主媒体后半段（c1/c3 由拆条产生）
]
```

| 字段 | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 必填 | 文档内唯一，`c<n>` 确定性递增，一经分配不复用 |
| `srcId` | string | `"main"` | 素材来源 |
| `in` / `out` | number | 必填 | **源时间**区间，`0 ≤ in < out ≤ 源时长` |
| `rate` | number > 0 | 1 | 变速；由 `clip set --rate` 写入，静态、不可动画 |

规范约束与语义：

1. **clip 引用的是媒体视图**：有效内容 = `[in, out]` ∖ 该源 cuts，折叠后进入时间轴。命令面与 UI 的入出点参数**说视图时间**，写入时经 `srcTime()` 换算落盘为源时间（§2.3 存储纪律）。
2. **时间轴位置是派生量**：clip 在时间轴上的起点 = 前缀和 `tlStart(i)`，不落盘。重排 = 移动数组元素，拆条 = 一变二（右半新 id），都不需要改其他 clip 的数字。
3. **真删除**：`clip remove` 从数组移除条目，数据模型不保留；可逆性由 `.bcut/history` journal 承担（timeline.json 每次写事务进历史库，undo/redo 端点零改动覆盖）。
4. **无覆盖不变量**：clips 是自由编排序列——不要求覆盖任何源、允许同源区间被多个 clip 复用（素材复用）、允许整段丢弃。老版"main 分区必须覆盖全长"的不变量随两层分离取消：无损性已由 cuts 层独立保证。
5. **拆条**：在时间轴 t（或词）处分割 = 定位所在 clip，换算为源时间切开。切点落在 cut 段内时吸附到相邻 kept 边界。
6. **空窗校验**：clip 的有效窗口（扣除 cuts 后）为空 ⇒ lint error（`clip-empty-after-cuts`）；新增 cut 导致某 clip 变空同样触发（提示删除该 clip 或 restore）。

## 3.5 词锚点

元素时间字段接受 `~<srcId>:<wordId>[:start|:end][±offset]`（BCF 附录 A 文法原样复用，`refId` 限定为 srcId）。求值链：词源时间 → 视图时间（词被剪——按 §3.3-4 中点规则——→ `word-anchor-cut` 错误；词保留但端点恰被 cut 削掉词头/词尾时，端点向词身所在 kept 侧吸附，同 §2.3 clip 端点语义）→ 时间轴时间（经引用该源的 clip；0 个命中 → `word-anchor-unmapped`（未编排）；多个 → `word-anchor-ambiguous`，需显式改写为秒或限定 clip）。求值发生在读取/渲染期，**落盘保留锚点字符串**——cut/restore、拆条、重排后元素自动跟随词，这是新协议相对老版的能力增量。

## 3.6 叠加轨与元素

```jsonc
"tracks": [
  { "id": "broll", "kind": "overlay", "name": "B-roll", "hidden": false, "locked": false,
    "elements": [
      { "id": "el-1", "kind": "video", "role": "broll",
        "start": "~main:g42.0", "end": "~main:g48.3:end+0.4",
        "srcId": "src-a1", "srcStart": 2.0, "muted": true,
        "place": { "x": 71, "y": 29, "w": 34, "radius": 28 },
        "mode": "pip", "fit": "cover", "bg": "blur",
        "animate": { "enter": { "preset": "rise", "dur": 0.5 },
                     "loop":  { "preset": "float", "period": 2.4 } },
        "ai": { "suggestionId": "sug-3", "query": "factory line", "reason": "…" } }
    ] },
  { "id": "text", "kind": "overlay", "elements": [
      { "id": "el-2", "kind": "text", "text": "三个瓶颈，一个答案",
        "start": 12.0, "end": 16.0,
        "place": { "x": 50, "y": 18, "w": 62 },
        "style": { "fontSize": 41, "fontColor": "#FFFFFF", "bold": true,
                   "background": true, "backgroundColor": "#101418A6",
                   "textOutline": { "on": true, "color": "#000000", "width": 14 } } }
  ] },
  { "id": "wm", "kind": "overlay", "elements": [
      { "id": "el-3", "kind": "text", "role": "watermark", "text": "@jimliu",
        "place": { "x": 85, "y": 10, "w": 22, "opacity": 0.6 },
        "tile": { "on": true, "angle": -30, "gapX": 8, "gapY": 10, "stagger": true } }
  ] },
  { "id": "bgm", "kind": "audio", "elements": [
      { "id": "el-4", "kind": "audio", "srcId": "src-b2",
        "start": 0, "end": null, "volume": 0.4 }
  ] }
]
```

**轨道**：`{id, kind: "overlay" | "audio", name, hidden, locked, muted, elements[]}`。叠放顺序 = 轨道数组序（下→上）× 轨内元素数组序，**没有隐式 canonicalRank**——迁移器负责把老项目的隐式序物化为显式数组序（§7）。字幕不占轨道：字幕仍由 transcript 派生、`studio/style.json` 定样式（并投影到 `studio/data.json.style`），渲染时垫在所有 overlay 轨之下、主画面之上（与老版合成序 `video → B-roll → 字幕/文字 → 水印` 的语义等价，但由"字幕层的固定位置"而非轨道注册表表达；元素若需压在字幕之下，放进更低的轨即可）。

**元素**（封闭字段集，`additionalProperties: false`）：

| 字段 | 适用 kind | 说明 |
| --- | --- | --- |
| `id` / `kind` / `name` | 全部 | kind ∈ `text · image · video · audio`（首版封闭集；shape/sticker/motion 见 §11） |
| `role` | 全部 | 语义标注：`broll · watermark · screentext`，缺省无。**只影响命令面选择器与 lint，不改变渲染语义**——水印就是带 role 的 text/image 元素（决策 7/8） |
| `start` / `end` | 全部 | **时间轴秒**或词锚点（§3.5）；`end: null` = 到片尾。窗口是半开区间 `[start, end)`。数字锚点在结构变化（cut/拆条/重排）后保持时间轴坐标不动（标准 NLE 行为），要跟内容走就用词锚点 |
| `hidden` | 全部 | 暂时隐藏该元素（不渲染、不导出，数据保留）；缺省 false，false 时不落盘 |
| `place` | 视觉类 | 归一化变换：`x/y`（中心点，画布 %，y 自顶）、`w`（宽 %；text 缺省内容自适应）、`scale/scaleY/rot/opacity`、`radius`（圆角，画布参考单位）。**画幅无关**是硬要求（§1.3 纠正 3） |
| `srcId` / `srcStart` / `rate` / `muted` / `volume` | image/video/audio | 媒体引用走 sources 表（`"main"` 合法——主视频画中画回切）；`srcStart` 是**源时间**；不接受裸路径 |
| `mode` / `fit` / `bg` | image/video | `fullscreen · pip`；`cover · contain`；contain 留边填充 `blur · black · #RRGGBB`（纯色自 `bcutTimeline` 0.12） |
| `text` / `style` | text | `style` **复用字幕样式 schema**（`studio/style.json` 投影字段中的字体/描边/阴影/底板子集）——文本元素渲染直接复用字幕渲染内核，Rust/JS 双端零漂移现成 |
| `stylePresetId` | text | 指向项目样式库（§5.2 `element style --save`） |
| `tile` | text/image | 平铺水印：`{on, angle, gapX, gapY, stagger}`；`on: false` 时整对象不落盘 |
| `mask` / `fx` | image/video | `{shape:"ellipse", feather}`；`{grayscale, blur, brightness}` |
| `animate` | 视觉类 | §3.7 |
| `keyframes` | 视觉类（`volume` 限 audio/video） | 0.12：`{属性: [{t, v, ease?}]}`，属性 `x/y/scale/scaleY/rot/opacity/radius/volume`，`t` 为元素本地秒或 `"N%"`；采样值取代静态值成为基础姿态，`animate` 叠在其上；`volume` 关键帧即音量包络。§3.7 末 |
| `duck` | audio/video | 0.12：`{under: "speech" \| 轨 id, depth?=10 dB, attack?=0.02 s, release?=0.35 s}`，别处有声时压低本元素。§3.7 末 |
| `ai` | 全部 | 溯源：`{suggestionId?, query?, reason?}`（B-roll）或 `{op:"screentext", srcText, frameT, blockId, conf, targetLang, appliedStart, appliedEnd}`（屏幕文字；`(frameT, blockId)` 是 apply 幂等键） |

**屏幕文字（screentext）**：不是独立类型——`kind:"text"` + `role:"screentext"` + `ai` 溯源的普通元素。OCR 工单队列仍在项目根 `screentext.json`（工作流状态，非文档数据），schema 与老版对齐（块几何用画布 %、`span.source ∈ detected|scan-refined|manual`、状态机 `pending|translated|skipped|applied`）。
扫描先原子抽取确定性采样网格，再以最多 24 帧的多页批次调用 Tesseract；一个批次失败会报告首尾帧且不提交队列，不改变逐帧几何与队列顺序。

## 3.7 动画

沿用 BCF 动画模型（决策 9），槽位适配剪辑域：

```jsonc
"animate": {
  "enter": { "preset": "rise", "presetVersion": 1, "dur": 0.5, "delay": 0,
             "intensity": 1, "ease": "easeOutCubic" },
  "exit":  { "preset": "fade", "dur": 0.3 },        // 缺席时按 enter 镜像派生，dur×0.75
                                                     // "none" = 显式无出场
  "loop":  { "preset": "float", "period": 2.4, "intensity": 1, "phase": 0 }
}
```

- **纯数据、封闭枚举**：preset id + 冻结版本 + 标量参数，无 keyframes 手写面（首版；自由 keyframes 是 BCF 编排能力，不进剪辑域）。缓动词汇表 = BCF 附录 A 封闭枚举；老版 `spring(response, damping)` 映射为 `easeOutBack`/`easeOutElastic` 近似（迁移表见 §7）。
- **loop 的确定性**：元素窗口有限，loop 在渲染期按窗口展开为有限周期的 keyframes——不违反 BCF"无 repeat"禁令，`sample(t)` 仍是纯函数。
- **文字分片级联**：`typewriter` 按 Unicode grapheme cluster，`riseWords` 按空白分词且中日韩文字逐字；`stagger` 可覆盖分片间隔，`staggerFrom ∈ start · end · center` 控制到达顺序。空白并入相邻可见分片，级联 spread 强制不超过 0.5 秒，短元素在已压缩入场窗口内重拟合；级联期间容器保持 identity，仅分片应用 `opacity/dy`，防止双重透明度。
- **preset 词汇表**（剪辑域子集，全端必须实现；与 BCF 附录 B 共用注册表，新增词条按 BCF preset 格式发布）：
  - 入场/出场：`none · fade · rise · drop · slideL · slideR · slideUp · slideDown · pop · zoomIn · zoomOut · spin · blurIn · typewriter · riseWords · wipe · compress · bounce · fall · skid · roll · wave · flipboard · dragonfly · billboard`（`typewriter`/`riseWords` 仅 text；映射 BCF 未来扩展 5"富文本子分割"的首个落地；2026-09-05 从 14 扩到 25，注册表 exit 配方 21 条——`pop`/`blurIn`/`typewriter`/`riseWords` 在 exit 槽合法但无配方）
  - 循环：`float · pulse · sway · jitter(seed) · blink · rotate · heartBeat · vogue · dragonfly · billboard · roll`（2026-09-05 从 5 扩到 11）
  - 参数约束沿用老版并进 schema：`dur ∈ [0.1, 2.0]`（吸附 0.05）、`period ∈ [0.2, 6.0]`、`intensity ∈ [0, 1]`，越界 `invalid_arg`。
- 可动画 kind：text/image/video；audio 返回 `unsupported`。
- **关键帧（`bcutTimeline` 0.12 起，修订上面「无 keyframes 手写面」）**：元素级 `keyframes` 是剪辑域自己的逐属性关键帧，不是 BCF 编排面——属性只有 `place` 的七个标量与 `volume`，采样值**取代**静态值成为基础姿态，`animate` 三槽仍叠在其上。命令行写法 `bcut element set --move "<属性>:<起>→<止>[:<缓动>]"`（写 `0%` / `100%` 两帧，随裁剪跟着元素走），完整多帧经 `bcut edit apply` 的 `patchElement`。静态盖满画布的图片 / 视频，运动全过程露底即拒绝（`--allow-uncovered` 放行）。完整契约见 [BCF 规范 §19.3「关键帧、纯色画布与闪避」](../../bcf/baocut-format-spec/19.md)。
- **音量与闪避（0.12）**：`volume` 仍是线性倍数；命令行 `--volume` 接受 `-6dB` / `80%` / `0.8`，回执与 `element list` 同时给 `volume` 与 `volumeDb`。`duck` 让音乐等元素在有人说话（`under:"speech"`，读已投影文稿的词区间）或另一条轨出声时压低 `depth` dB；活动只从文档读。最终增益 = 音量（静态或关键帧）× 淡入淡出 × 闪避，导出与两端预览同一个纯函数 `bcut_timeline::element_gain_envelopes`。

## 3.8 主画面与画布

```jsonc
"main": {
  "place": { "x": 50, "y": 50, "scale": 1, "rot": 0 },   // 主画面变换（归一化）
  "muted": false,                                          // 主轨音频整体静音
  "background": "blur"                                     // 画布填充：blur | black | #RRGGBB（0.12）
}
```

画布尺寸/画幅**不落盘**：预览缺省主媒体自然尺寸，导出期由 `--ratio/--size` 决定（对齐老版 `outputSize` 语义）。归一化坐标保证同一 timeline 在不同画幅下语义稳定。

## 3.9 剪切溯源：`ai/cuts.json`

与其他 AI 阶段产物同级的 append-only 工件（不进 timeline.json，避免高频编辑对象混入审计日志）：

```jsonc
{ "entries": [
    { "id": "cut-1", "kind": "silence",        // silence | filler | badTake | manual | match | offScript（1.291.0 起）
      "t0": 12.40, "t1": 13.10, "srcId": "main",
      "reason": "1.9s pause", "detail": "…",
      "origin": "detect",                       // detect | cleanup | manual | match
      "category": "pause",                      // 可选：filler | pause | retake | falseStart | repeat（cleanup 细类，kind 是闭集投影）
      "via": "review",                          // 可选：flow（cleanup 直接应用）| review（逐项接受）| ui（剪辑态手动）
      "batch": "cleanup-1757230000000",         // 可选：所属 cleanup 扫描批次，收据整批撤销靠它
      "at": "2026-08-01T10:12:00Z" } ],
  "params": { "minPause": 0.8, "compressTo": 0.3, "maxGap": 3.0, "fillerLang": "auto" },
  "fingerprint": "sha256-…" }
```

按 id 归并追加，永不整体替换；cuts 条目用 `ref` 反向指到溯源。restore 不删溯源条目（审计保留）。`check` 在"有 cut 但无溯源"时 warn（对齐老版 audit）。

## 3.10 校验规则（Schema + lint）

Schema 硬错误：字段封闭集、kind/preset/缓动枚举、cuts 排序无重叠、clip 区间合法、词锚点文法。

lint（并入 `bcut check` 报告，剪辑域规则组）：

| 规则 | 级别 | 说明 |
| --- | --- | --- |
| `cut-mid-word` | error | cut 边界落在词中间（偏离词边界 > 呼吸垫） |
| `clip-empty-after-cuts` | error | clip 有效窗口被 cuts 掏空（§3.4-6） |
| `clip-source-missing` / `element-source-missing` | error | `srcId` 不在 sources 表 / 文件缺失 |
| `word-anchor-cut` | error | 词锚点指向被剪掉的词（§3.5） |
| `word-anchor-unmapped` / `-ambiguous` | error | 词未被任何 clip 编排 / 多 clip 复用未限定（§3.5） |
| `element-window-void` | warn | 视觉元素窗口不与任何画面内容相交（越出时间轴末尾等） |
| `element-rect-out-of-canvas` | warn | place 越出画布（视频 / 图片盒左右都越出、盖满整幅宽的是放大取景，不报，`1.269.0`） |
| `cut-ratio-high` | warn | 某源删除量 > 40% |
| `cut-into-head-tail` | warn | 剪切侵入源首尾 3 秒 |
| `cutaway-flash` | warn | fullscreen B-roll < 1.5s 闪切 |
| `cut-no-provenance` | warn | 有 cut 但 `ai/cuts.json` 缺失或无对应条目 |
| `element-window-overrun` | warn | video 元素源时间越过素材末端（冻结末帧，同 BCF §6.5） |
| `picture-not-following-cuts` | warn | 分离文档里片段的画面还停在剪口之前的位置（旧版本剪口没带走画面）；下一次改时钟的写入自动修好（BCF §19.1 跟随第 1 条，`1.283.0`） |
| `clip-unused-source` | info | sources 表条目未被任何 clip/元素引用 |
