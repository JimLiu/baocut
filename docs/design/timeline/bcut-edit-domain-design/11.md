# 11. 开放问题与风险

> 出自 [BaoCut 剪辑域协议设计（Cut / Clip / 元素 / 水印 / 工程导出）](../bcut-edit-domain-design.md)

1. ~~**元素 kind 封闭集**：首版 `text/image/video/audio`；老版 `shape / sticker(template·asset·waveform) / motion` 使用率待产品确认后再入集（sticker-asset 可先按 image 迁移）~~ → **已定案**（EF P0，`bcutTimeline 0.2`，见 [bcut-element-render-foundation-design.md](../../bcf/bcut-element-render-foundation-design.md) 与格式规范 §19）：`shape / sticker(template·asset) / visualizer / progress` 四 kind 转正，waveform 子类型废弃、迁为顶层 `visualizer`；motion 仍暂缓。`bcut element add --kind` 尚未扩到新四类（走 `timeline apply` 的 `addElement`）。扩集是加法演进，不破坏 schema。
2. **附加源的润色/分段/章节**：翻译管线已由 §4.2 定案（时间轴投影装配 + 散写回 + 可见词指纹）；润色/分段/章节是否同样按时间轴投影跨源运转、还是仍以单源为单位，另行排期（倾向前者——与翻译同构）。
3. ~~**数字锚点元素与结构变化**：cut/restore、拆条、重排会改变时间轴长度，数字锚点元素保持坐标不动（内容在其下方移动）。是否为 `timeline/apply` 提供可选 ripple 语义，待编辑器交互设计定案~~ → **已定案**（2026-09-28，CLI `specVersion` 1.283.0，[剪辑工具缺口方案 §2.1](../bcut-agent-editing-gaps-plan.md)）：凡是改变投影的写入都让元素跟随时钟，不是可选项——片段名下的视频元素收到剩下的源区间，其它数字时间元素按「旧成片时刻 → 源时刻 → 新成片时刻」换算，跨剪口的只缩短不挖洞；`clip move` 只带走整件落在该片段里的元素；词锚点与不设终点的元素不动。规则与回执见 [BCF §19.1](../../bcf/baocut-format-spec/19.md)「元素跟随时钟」，规范实现 `bcut_timeline::follow_clock`。
4. **烧录性能**：多路解码 + 逐帧叠加已接通；4K 长片的发布基线仍需按目标机器持续实测。退路是区间预渲染 overlay 序列（同内核产物），无渲染降级选项。
5. **CapCut 版本漂移**：9.x 后续版本草稿字段可能变化；净室模板 + draft lint + 版本白名单的机制保留，新版本按实机校准追加。
6. **`clip.rate` 变速**：字段已预留，开放写入前需先解决变速下的词锚点映射展示与 CapCut `speed` 段往返测试。
7. **Studio Web 剪辑 UI**（2026-08-02 审计登记）：`timeline/apply` 端点与投影已备，前端只有播放跳段与译文路由；clip 轨道、剪切/拆条/重排交互整体缺席。多表面同步义务下这是最大的表面不对称（designs/ 原型与 Mac 均有剪辑面）。2026-09-07 起口播剪辑态（文稿划词剪、AI 建议逐项审阅、时间轴剪口标记）的方案与 App v2 落地见 [`bcut-talking-head-cut-design.md`](../../editor/bcut-talking-head-cut-design.md)。
8. **Mac 细粒度 op 与跨源播放收口**（2026-08-09 更新）：OUTPUT ↔ source seek、播放时钟回读、source cut 跳段和同媒体 clip 入点切换已消费 `TimelineMapping.swift`；剩余工作是 clip 边界跨 `srcId` 时切换 AVPlayer 媒体。写路径仍需由 `replaceTimeline` 过渡到 §5.3 细粒度 op（拿回逐条 base 校验/skipped 语义），软删写回仍需生成 `sources[].cuts` 条目而非移除 clip。
9. **§4.3 BCF 编译桥**：烧录/转场当前自行实现采样（与预览经 fixture 对拍维持一致），"消费 BCF 展开"的架构约束尚未落地——落地时机与 `export --to bcf` 一并排期。
10. **工程导出 golden 字节冻结**：六目标现为结构断言回归，格式化/属性顺序漂移无兜底；发布候选验收前补字节冻结 fixture。
