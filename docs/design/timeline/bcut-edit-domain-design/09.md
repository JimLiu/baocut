全面审计并修复了一批语义缺口（词剪切中点规则归一、WordSpan 帧对齐次序、事务后

元素/动画与三端契约夹具；CLI/serve/Studio/Mac 使用同一 `timeline.json` 真相和历史

`bcut-editable`、导出注册表、CapCut portable/install writer 与其余五个 writer 均已
接通，六目标共用一个 OUTPUT IR 和 preflight。老项目迁移器、公开 skill 剪辑面、

投影消费与跨源译文编辑路由，但**剪辑操作 UI 与 `timeline/apply` 调用尚未落地**；
Mac 编辑器写路径仍走 `replaceTimeline` 整文档提交（细粒度 op 未接），原生播放器已用
`TimelineMapping.swift` 把 OUTPUT seek/时钟回读映射到当前 clip 的 source/kept segment，
会跳过 source cut 并在同一媒体内跨 clip 入点；跨 `srcId` 的 AVPlayer 媒体切换仍待接入。
软删写回仍会把 cut clip 落为 clip 移除而非 `sources[].cuts` 条目。

FCPXML、MLT golden、旧项目单层→两层 fixtures、六目标注册表/finish-check 以及
Rust/JavaScript/Swift 时间线投影对拍。把生成工程交给已安装的特定 CapCut/剪映、
Premiere、Resolve、Final Cut Pro、Shotcut、Kdenlive 版本实际打开，仍属于发布候选的
