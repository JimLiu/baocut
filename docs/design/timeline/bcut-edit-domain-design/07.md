# 7. 老项目剪辑数据补迁移

> 出自 [BaoCut 剪辑域协议设计（Cut / Clip / 元素 / 水印 / 工程导出）](../bcut-edit-domain-design.md)

`bcut upgrade-baocut` 已实现原位升级；旧 `import-baocut` 只保留为隐藏兼容别名。迁移的落位与执行机制（原位静默升级、`archive/` 归档、字幕样式补迁移）由 [bcut-legacy-upgrade-design.md](../bcut-legacy-upgrade-design.md) 规定；本节的字段映射规则继续有效。老版单层分区在新模型下**拆成两层**：

| 老 doc.json | 新落位 | 说明 |
| --- | --- | --- |
| `clips[]` 中 `cut: true` 的条目 | `sources[srcId].cuts[]` 条目 `{t0: src, t1: src+(end-start)}` | 剪切归源内（决策 10）；`ai/cuts.json` 条目经 id 对齐补 `ref` |
| `clips[]` 中 kept 条目 | `clips[]` 条目 `{srcId, in: src, out: src+(end-start)}` | 按老 start 排序取数组序；相邻同源无缝 kept 段**保持分立**（保留老结构，合并是编辑行为） |
| `sources[]` | `sources` 表 | `media/` 相对引用保持不变，绝对路径保持外部引用语义；不复制资源 |
| `tracks[].elements[]`（含 legacy texts/broll/watermarks 投影） | `tracks[].elements[]` | 字段基本 1:1（% 坐标语义相同，归入 `place`）；元素 start/end 从老时间轴坐标换算为新时间轴坐标（经老分区折叠映射）；隐式 canonicalRank 物化为显式数组序 |
| `kind: sticker/shape/motion` 元素 | **不迁移**，逐条记入 `migration.json` 明示 | 首版元素封闭集外（§11） |
| `source:"html"` 水印 | 其栅格化 PNG 归入 image 元素，`html` 丢弃并明示 | 决策 7 |
| `anim {enter/exit/loop}` | `animate` 同名槽 | preset id 同名直迁；`spring` ease → `easeOutBack`；`tracks: [CompiledEffect]` 覆盖形态不迁移（明示） |
| `ai/cuts.json` / `screentext.json` / `ai/broll-suggestions.json` | 新格式写入兼容位置，旧文件归档 | 溯源与工单延续 |
| `doc.main` / `videoTrackMuted` | `main` 节 | — |

迁移可重入、单项目失败不阻断的机制沿用 [§4.6](../../../archive/mac/bcut-mac-app-port-design.md)。仓库夹具
`core/fixtures/legacy-upgrade/appdata/` 覆盖老索引、doc、flat 字幕样式、字幕轨道与明确损失
字段；Rust dry-run 回归验证结构化损失与零写入，另有原位终态、cancel/kill -9 续跑、
时间轴映射以及 Rust/Swift 样式契约对拍。
