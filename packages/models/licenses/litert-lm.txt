LiteRT-LM 0.18.0 for Windows x64 (litert-lm.dll) - license and third-party notices
====================================================================================================

BaoCut builds litert-lm.dll from the unmodified LiteRT-LM source at tag v0.18.0
(https://github.com/google-ai-edge/LiteRT-LM, commit b2f686e) with upstream's Bazel configuration for Windows
(MSVC, `bazel build //c:litert-lm`), adding only `--define=LITERT_LM_FST_CONSTRAINTS_DISABLED=1` so that the
prebuilt libGemmaModelConstraintProvider.dll is not linked. The DLL statically links the components listed below;
their license texts follow, taken from the exact source trees used by that build. Rust code in the DLL also links the
Rust standard library (MIT OR Apache-2.0, https://github.com/rust-lang/rust).
