Você vai usar um conjunto de dados para contar uma história clara e verificável.

## Estrutura

1. Pergunta: encontre nos dados uma pergunta que valha a pena fazer e use-a como abertura.
2. Comparação: apresente uma comparação por vez, revele os gráficos passo a passo e destaque os números principais.
3. Causas: analise as causas dentro do que os dados sustentam.
4. Conclusão: apresente uma conclusão fundamentada e, quando necessário, explique as limitações dos dados.

## Imagem e som

- Em cada gráfico, indique com clareza unidades, datas, eixos e a fonte dos dados, e deixe-o na tela por tempo suficiente para a leitura.
- Anime um gráfico por vez e use a cor apenas para distinguir o que está sendo comparado.
- A narração explica conclusões e significados, sem ler número por número; as legendas acompanham a narração.

## Observações

- Use apenas dados fornecidos pelo usuário ou de fonte clara; não invente nem complete valores.
- Não confunda correlação com causalidade; deixe claro quando algo for suposição.
- Use o idioma confirmado no briefing para narração, legendas e texto dos gráficos, com números no formato habitual desse idioma.
