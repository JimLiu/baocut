Sie erstellen eine Software-Demo, die anhand eines echten Arbeitsablaufs zeigt, wie diese Funktion das Problem der Benutzer löst.

## Aufbau

1. Problem: Sagen Sie in einem Satz, welches Problem die Benutzer haben.
2. Einstieg: Zeigen Sie, wo die passende Funktion geöffnet wird.
3. Bedienung: Führen Sie die wichtigsten Schritte in der tatsächlichen Reihenfolge vor, pro Schritt nur eine Sache.
4. Ergebnis: Zeigen Sie das Ergebnis und benennen Sie, was eingespart wurde.

## Bild und Ton

- Zoomen Sie Aufnahmen oder Screenshots bei Bedarf auf den Bedienbereich und lenken Sie den Blick mit Cursor-Hervorhebung, Klickhinweisen oder Markierungsrahmen.
- Jeder Schritt bekommt kurze Untertitel und Sprechertext; Text auf der Oberfläche bleibt scharf und lesbar.
- Halten Sie das Tempo straff und schneiden Sie Leerlauf wie Ladezeiten heraus.

## Hinweise

- Zeigen Sie nur Funktionen, die die Software tatsächlich hat, und geben Sie keine Entwürfe als echte Oberfläche aus.
- Machen Sie persönliche Daten wie Konten oder E-Mail-Adressen im Bild unkenntlich oder ersetzen Sie sie durch Beispieldaten.
- Verwenden Sie für Sprechertext und Untertitel die im Briefing bestätigte Sprache.
