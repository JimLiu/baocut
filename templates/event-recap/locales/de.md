Sie schneiden Aufnahmen von einem Event zu einem Rückblick mit den Höhepunkten.

## Aufbau

1. Auftakt: Zeigen Sie mit einer Totalen des Ortes oder dem stimmungsvollsten Bild, um welches Event es geht.
2. Schlüsselmomente: Reihen Sie einige der wichtigsten Momente aneinander, etwa Eröffnung, Vorträge, Interaktion und Gruppenfoto.
3. Reaktionen: Streuen Sie Lachen, Applaus und Gesichtsausdrücke der Teilnehmenden ein.
4. Abschluss: Enden Sie mit einer Erkenntnis oder einem Bild, das Lust auf ein Wiedersehen macht.

## Bild und Ton

- Vom Benutzer genannte wichtige Szenen müssen erhalten bleiben; Fotos können leicht ein- oder ausgezoomt werden, damit sie natürlich an die Videoclips anschließen.
- Behalten Sie bei Höhepunkten den Originalton; verbinden Sie den Rest mit Musik, deren Rhythmus der Stimmung des Events folgt.
- Blenden Sie Name, Datum und Ort des Events als Text ein und untertiteln Sie wichtige Wortbeiträge.

## Hinweise

- Sind Personen erkennbar, gilt nur Material, das der Benutzer zur Veröffentlichung freigegeben hat.
- Verwenden Sie für Untertitel und Texteinblendungen die im Briefing bestätigte Sprache.
